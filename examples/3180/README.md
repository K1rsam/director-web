# 3180 案例：柔光鸢尾·浅

这里就是与用户核对的 **3180 第五轮交互样稿**。以后提到“3180 案例”“3180 效果”，均指本目录，不依赖原来那台 Windows 电脑。

## 打开完整交互

安装 Node.js 后，在仓库根目录运行以下命令；仅看案例无需安装项目依赖、配置数据库或登录：

```bash
node examples/3180/serve.mjs
```

浏览器打开 [3180 案例](http://127.0.0.1:3180/index.html)。也可以用 `npm run preview:3180`。端口已占用时加 `--port 3181`。

也可下载 [index.html](index.html) 后直接双击，图标、玻璃材质和切换交互已包含在文件内；复制功能建议通过上面的 localhost 地址使用。**GitHub 文件页展示源码，需下载或本地启动才会显示完整网页。**

建议用浏览器 100% 缩放查看。1920×1080 是显示器尺寸，实际页面高度要扣除浏览器工具栏，侧栏应适配可用高度。可体验主题切换、左侧导航、制作流程、内容页签、按钮样式和本集信息包。
