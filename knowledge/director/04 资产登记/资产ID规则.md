# 资产ID规则

当前版本只做资产登记，不负责生成角色图、服装图、场景图和道具图。

## 资产类型

- `CH-001`：人物。
- `LOOK-001`：人物造型或状态。
- `LOC-001`：场景或地点。
- `PROP-001`：道具。
- `STYLE-001`：项目风格。
- `NEG-BASE`：通用负面约束。

## 使用规则

- 新人物、新场景、新道具必须先登记 ID。
- 分镜单元只引用 ID 和简短名称，不反复展开外貌。
- 用户根据 ID 自行生成或调用对应图片。
- 后续设计师分支成熟后，再把资产图生成流程接入。

## 示例

```text
CH-001 叶风
LOOK-001 叶风下山布衣装
LOOK-002 叶风宴会装
LOC-001 起灵山龙殿练武场
PROP-001 平安扣玉佩
STYLE-001 现代都市武道爽剧写实风格
```

## 分镜引用格式

```text
[资产索引]
CH-001 叶风；LOOK-001 叶风下山布衣装；LOC-001 起灵山龙殿练武场；PROP-001 平安扣玉佩
```
