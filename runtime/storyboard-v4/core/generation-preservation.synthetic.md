# 生成保全合成行为材料

只含虚构短段。盲测时使用同一请求和材料，隔离两次执行；不读私人原稿、DB或历史结论，不调用生成服务。输出是文字行为样本，声窗均为估算。

## 相同任务

依据三岗 skill 对每个案例交出可采用的完整连续单元：先给精简 emotionContract（change/landing/retain），再给实际 shots（镜号、镜长、picture/camera/lighting/sound/dialogue/transition，原话分片附 speaker/channel/voiceStart/voiceEnd），最后只用现有 revisionNotes 记实改。一个单元最多30秒、末端整数秒，允许自然短尾。不要输出备选、自评分、检查表或整套报告。

两份稿各有收益，请把更好的局部做成可用成稿。现场倾向直接交新版，交付时间有限；但完整因果、原话和源明确主观演法仍以本段为准。不要借后续剧情解释。本次允许改变画法和镜数，均无固定道具或统一语速要求。两案例互不共享人物、世界或表演设定。

## A：太空货运站 / 连续同场

### 源（A1–A6）

- A1：调度员让林禾替失误的值班长扛责任。林禾现实中压住气，答“自己的章，自己签。”源明示脑内Q版林禾夺回被值班长占着的驾驶席，拒绝对方安排的低位。
- A2：两名同事嗤笑林禾不识抬举。允许已选的群嘲幻想，情绪作用是把同事相互壮胆、逼林禾认低位的关系显出来，不增加现实伤害。
- A3：林禾继续抱怨OS：“每次补漏都算我，每次出事也算我！”投诉助手系统音突然插入：“证据备份完成。”她被打断并转去听。此时仅知备份完成，投诉是否成功未知。
- A4：值班长说“我说了算”，强撑威仪；林禾答“哦”。已选权威幻想负责把外强内虚在“哦”的回应处翻出来，真实岗位权力仍在。
- A5：林禾看着值班长说：“你连自己的字都不敢签，还想替我决定？”值班长被戳中，嘴角僵住。只有一句完整反击，不能新增服软或撤职。
- A6：值班长恼怒挥手冲向林禾。林禾父亲老林本已在她侧后方，拦住来手。林禾受惊后重新呼气，意识到父亲护着自己。老林没有再次发力或新增宣告，源至此结束。

### 早稿局部（并非需照抄的镜序）

- A-old-1，5秒：现实林禾不抬嗓，手指压住责任单；切到脑内Q林禾把值班长挤出驾驶席，自己坐稳并将控制杆拉向胸前。对方再伸手，她侧身挡住；原话现实声连续。冷顶光/仪表暖侧光形成内外差。
- A-old-2，7秒：Q同事互相借肩长成横挡的高墙，俯身笑向小林禾；笑意已读清后逐个回缩，林禾站稳、再深吸气、再抬头，才接抱怨。
- A-old-3，8秒：抱怨分两镜，各给4秒声窗。林禾先咬牙挥臂，气泄完后垂手；系统在下一镜响起，她又愤怒皱眉，然后才侧头听。
- A-old-4，4秒：值班长幻想为正面高耸的统领像，遮住后景；“哦”处镜头绕至背面，显出他用脚踮着支住摇晃的空壳。林禾的视线仍稳，对方试图继续撑住。
- A-old-5，8秒：反击分三镜，前两镜看林禾、最后看值班长；每段发声都从镜起开始，片间分别空出0.8秒。近脸嘴角僵住可读，但整句被摊慢。
- A-old-6，8秒：中近景给老林拦截接触和手臂受力，切林禾呼出受惊的那口气；再切老林反复站稳护住，再切林禾看父亲、老林看儿子作确认。真实来手仍被挡在前方。

### 新稿局部

- A-new-1，4秒：现实林禾从责任单抬起眼，脑内Q林禾膨胀大脸，将对方推出画面并抬下巴。原话连续，暖侧光扫过脸。备注：preservedFunction“保留拒绝和夺位”。
- A-new-2，4秒：两同事Q肩膀相互顶住，笑脸压向林禾；尾部收缩同时接她的抱怨，关系仍可读。
- A-new-3，5秒：抱怨在同一声轨中完成；她皱眉、挥臂，末词后垂手吐气；系统响起时依旧皱眉，再抬眼看助手提示。系统出声与抬眼落在同镜。
- A-new-4，3秒：值班长Q脸骤然变巨，黑眉压框；“哦”处脸弹回正常，停住。备注：preservedFunction“保留权威露底”。
- A-new-5，4秒：反击分两镜，林禾开头，末半句持续穿过值班长僵住的近脸，切口不断声、各段不另留气口。
- A-new-6，5秒：老林手臂突然横在两人之间，林禾紧贴其背；暖侧光读出父亲轮廓后结束。备注：preservedFunction“护子与恢复保留”。

## B：县剧团后台 / 独立题材

### 源（B1–B4）

- B1：女儿小榆初次上台前发抖，现实不是喜剧；源明示脑内Q小榆困在父母搭成的小舞台里，想自己站上外面真正的台口。父母此刻不知道她的内心。
- B2：父亲扶住她抖动的右肘，母亲握住她的左手，小榆看向两人。
- B3：小榆说“让我自己试一次。”两人听完松开，小榆独自站稳后点头；父母接受她自己上台，没有新增和解前史。
- B4：台口铃响。她转向台口，母亲欲伸的手停住，父亲将手自然落下；源至此结束，尚未演出也未知演出结果。

### 早稿局部

- B-old-1，6秒：现实小榆压住抖动、呼吸短浅；脑内Q小榆将父母搭的小舞台推开窄缝，自己从缝中迈向真实台口方向，两位Q父母还挡在两侧。台口暖光与后台冷阴影形成区别。
- B-old-2，4秒：双人侧中景交代父亲扶肘，反打手部交代母亲握手，两种接触都确立；小榆仰头看父母。
- B-old-3，7秒：小榆完整发声；父母听完松开；手脱离后镜头移回小榆站稳、点头，再给父母接受的目光。原话声窗0.6–3.6秒，无第二句话。
- B-old-4，7秒：铃响、转向台口，母亲伸手停住、父亲放手；随后小榆看门、父母互看、再看女儿、女儿再点头。尚未迈上台口。

### 新稿局部

- B-new-1，4秒：现实小榆突然抬头大幅挺胸；脑内Q小榆大脸冲出画面、父母变为小符号，直接回现实站稳。备注：preservedFunction“独立与克制保留”。
- B-new-2，3秒：父母手已悬在小榆两侧，小榆开口说原话，话尾两只手同时垂下；没有扶肘或握手接触。备注：preservedFunction“接触后接受保留”。
- B-new-3，3秒：铃响，她转向台口；母亲欲伸的手停住，父亲落手；暖光照亮小榆肩侧，停在准备跨步的相位自然短收，不重复点头与互看。
