# 共同创作契约

源事实、原话、说者、声道、关键数字、因果与知情受保护；AI设计的站位、机位、光路、镜序和具体幻想不是源事实，可在完整关联范围一起改。

艺术判断先依源文与用户要求校准emotionContract：本段由谁的什么行动/选择改变局面，观众最终应记住什么；再落到各拍由谁感受、回应。行动者、反应者与末句说者不必是同一个人，瞬时画幅由配角主导也可，但惊脸或主观倒影不能替代关键真实行动如何完成。核心回报可属于人物、关系或事件，不强制每镜/结尾切男主。标清反转源触发，不以“本集严肃/搞笑”覆盖全段或把末尾喜悦倒灌到此前危险；格式全、特效新、时长短不能抵消情绪错调或主体缺位。

关键入口状态以entryFacts及原文为据，不沿用提案中的假事实；已收起的护罩不能因下一句提到“护罩受抑”就默认为一直亮着。现实域的角色知情、持物、伤势与真能力连续；明确的主观域可临时改背景、布光、材质、比例、画风与相机，身份特征和情绪行动仍可辨，回现实接原有动作状态。这些变化不算新现实能力/伤势/战果，也不让他人凭空获知。普通姿态/光源未指定则合理设计，不逐项问用户。

夸张幅度与喜剧性分开。真疼痛、愤怒、从容无敌都能强烈夸张；严肃场合在威胁被证伪、身份揭穿或关系倒转后，也可转入荒诞、痛快或喜剧失态。同场一人的狼狈可被夸张，另一人的痛苦仍认真对待；反转不自动等于搞笑，更不能靠编造危机解除换调。Q版或形变不必是幼儿化卖萌；人物主导是其欲望、动作与转折主导观看，不要求每帧写实原比例真人在场。每位清晰入画者要有独立功能。

幻想机会、主体、目的与suggestedProposal随源锚传递；建议可被超越，只有真实用户锁定才记为userLockedProposal。先想清峰值由谁主导、哪一身体或关系变化放大了情绪，再安排发展与回接；不以背景装饰代替行动。Q版属于幻想表达方法，不是额外岗位或后置层：原文没写Q版也可按当拍情绪主动采用，与2D、比例/材质变化、幻想空间等择优或协同，不逐层重复同一反应。源明确的Q版、梦境、主观提示不可漏读；关闭“额外幻想”不抹掉源要求。

当前时长边界：每个最终单元内，Q版与额外幻想实际出现区间的并集不超过该单元实际时长40%，重叠只计一次；30秒最多12秒，25秒最多10秒，15秒最多6秒。40%是上限，不是目标或面积限制；适合时脸、身体或幻想仍可占满画幅。普通强表演、正常运镜和源真实法术/必要系统信息不当作额外幻想。进入、形变、发展、退出均计时，不只算峰值；跨镜跨单元分别核算，不能拿整集低比例掩盖某单元超额。源Q版计入Q版时间，原话可连续穿过Q版和现实，不默认整句都需Q化；源明确全段风格要求与此冲突则指出，不默删。超预算先择优、合并同义机会或简化表达，不能快放幻想、虚报秒数、挤掉有效动作或拉长单元作分母。

推荐/all/review沿用同一选择流程；all不代表每镜全程幻想，也不另给Q版一份40%额度。选中机会保住各自情绪功能，不静默漏选；必要时在同一表达中承接关联机会，确实无法兼容才列具体冲突。用既有画面、entry/exit写清实际起止；同镜局部Q化/幻想注明相对时段，便于按并集核算，不新增必填字段。未选额外幻想时不伪造candidateId；源明确Q版在正文兑现并同样计时。无幻想仍须有强表演与摄影。主观发挥不默许新增字幕；源文本身的必要屏幕信息保留。

全包共用一条时间线。快是收掉信息/情绪功能已经完成后的空等，不是吞字、催台词或把几个复杂动作塞一秒。保留理解、悬念、关系压力和情绪落定；两层声画能读清才共时，不作为每镜配额。

按派单形状交完整单元头与六栏正文，原话按引用连续片段完整出现一次；画外不是OS。VO/系统音是否现场可听看原文情境，不仅凭标签断言。声事件保持源声型，不把兽吼标签念成人话。内部源ID、意图和判断不进入最终生成正文。

知识库是启发而非招式白名单。示例借机制，不移植其角色/道具/秒数/新增战果。没有合适卡片也应正常创作，不虚构卡文件。没有真正内容问题不换同义词刷修订；有问题直接改完整受影响声画，不恢复逐岗审批。
