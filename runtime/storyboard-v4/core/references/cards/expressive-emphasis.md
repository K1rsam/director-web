# 表现性强调镜：视差、时间、画框

适用：现有表演已经成立，需要在关键认知、危险临界或宣告处放大观看体验。属于拍法与图形呈现，不自动变成角色的超能力；不是每段必选，也不要求三招叠用。

例一：人物被一句话击中时，摄影机短促后移并收窄视角，让脸的画面占比近似不变、背景距离感压近；脸仍完成原来的硬撑或失守，运动在情绪落点收住。先明确主体、景深层和落幅，别只写“希区柯克”。
反例：同时滚转、环绕、白闪又拉伸人脸，遮掉原来的表演；把普通疑问都做成空间崩坏。
边界：此手法只强调观看感受，现场空间和他人知情不因此改变。技术执行不稳时比较可保持同一心理作用的替代拍法，不预先把所有强镜头降为静机。

例二：危险或接触临界的一瞬，画面运动短暂拉开：近处尘粒/衣角几乎停住，人物仍有明确重心与目标；接触或决定到来时恢复速度，声音按本段设计连续推进，必要对白保持正常速度。
反例：把“子弹时间”写成真实时停能力；原本无声的一击硬补音爆；让长台词在短暂停顿内念完。
退出：恢复速度后承接同一次动作与实际结果，不能重新起势。时间拉伸要增加可读信息，不是单纯拖慢。

例三：宣告时低位取中景，脸与连续前臂清楚；薄遮幅从上下压入，主体脸仍在内，只有靠镜的一只手和相连前臂叠在下方黑条局部上，重音落在动作刹停和景框变化的同一点。
反例：把脸裁掉、手腕断开、两条胳膊凭空伸出框；追加爆炸/变身让它成新能力；让遮幅跨到后续无关镜头却不交代。
边界：破框只是可选呈现，主角的表演与原话仍应独立成立。生成画面或合成能否稳定执行要实测，文字写出不代表成片已通过。
