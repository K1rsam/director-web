# 情绪驱动的幻想表达

这是规划/主创/整编内的可选方法，不是固定后置岗位。先看源事实和emotionContract；可选的是是否使用，不是等30秒排满后才开始想。目标是情绪更强、更准，不是特效更多。

Q版归本方法，不单设Q版层或员工，也不限于原文点名。它改变身体比例/画风而不自动改变情绪：得意可以膨胀，尊严受损可以憋住，恐惧可以紧缩，强者可以小身形却稳稳完成源行动；保留身份特征、年龄气质与人物策略，不把所有人变幼儿或吉祥物。与其它幻想按同一机会择优，不能Q版先反应一次、幻想再反应一次。源明确Q版须有正文落点，额外Q版受幻想开关控制；off不等于删源Q版。

按每拍、每个人重判欲望、阻力和情绪转折，不用开场气质盖住全场。肃穆场合在源剧情戳破误会、逆转权力或解除威胁后，也可荒诞、搞笑或夸张解脱；同场一人的虚张声势可变笑点，另一人仍在的伤痛须保重量，不要求全部危险解除才允许局部反差。反转不自动等于喜剧，形变幅度与喜剧性也不是一回事。

选中幻想就按**幻想增强档**创作：先确定它服务本段哪一回报，再构想峰值画面并组织到达过程；这是创作顺序，不是提前播放高潮。答清谁感受、谁主导这一幅、形体/尺度/空间因果怎样不可能、身体如何应对。反应者可占满画幅，但他眼中的行动者不能替代后者真实完成的关键动作。夸张须能看懂、能复述，不只标签或大背景小反应。

先选这个人的应对策略，再选材质。想藏窘态的人手先遮，想否认的人躯干想退却忍不住前探，想求生的人注意退路；形变沿这些矛盾发展，不把所有惊讶都演成“撑住—压扁—跪下”。同材质可统一风格，换材质也不等于换表演；当前范围内相邻反应若只是同一流程换人，先区分其欲望、误判与动作，除非齐反应正是本拍目的。内部择优，不输出备选清单或自评分；没有跨集资料不假称已检查全剧重复。

脸或身体本身可以就是幻想，不只是在巨墙、巨物旁保留一个小人。巨大近景、Q版本人、二维脸、纸质身体、2D/3D混合、材质替换、画风突变、全幅环境互动与夸张相机都可承担欲望和抵抗；身份特征与动作意图仍可辨。人物主导不要求每帧有写实原比例真人，必要空场或意象可承接观看，但不能代演人物的峰值。方法库、用户举例与已有样稿都是启发，不是形式上限。

Q版与额外幻想遵守共同契约：逐最终单元的出现区间并集≤实际时长40%，重叠只算一次；上限不是必达量，也不是画幅限制。比如25秒单元内，Q版在4–8秒、幻想空间在6–11秒，共7秒，不是9秒；无需缩成小角落。进入、读懂、发展、退出全算，跨单元分别核。原话可与夸张共时，但不能将复杂变化加速塞进极短窗；需要更多可读时间就简化形式或重选机会，不削基础表演、不加空白抬分母。同一情绪可跨镜，不强制三段式来回。

选择机会先问“增益在哪”：是把关键词变成一眼懂的欲望/压力，还是只让抽象背景变漂亮？私下得到底气与公开作出反击，应分别确定有力表演；不能在前者花尽视觉注意，后者只普通念词。世界规则可作明确主观示意，呈现源已给出的关系，不把“不能新增真实经历”扩大成只能画无内容折面。推荐与all模式都遵守同一预算，形式多样不等于每段都用。

明确主观归属后可临时换背景、布光、比例、材质、画风与相机；现实中的身份、原话、说者、声道、持物、伤势、真能力、知情和结果仍按源文。幻想不能冒充实际攻击、救援或战果，也不默许新增文字字幕；漫画线条、图形问号不是新台词。进入与回接处交代清楚边界，不让逐镜否定句挤掉正向画面。

围绕峰值把触发→身体行动→夸张场面/运镜→必要回接组织成同一声画过程。同镜渐变、突变、动作或声音匹配均可，原话可从触发时起、穿过幻想继续；形变说话仍有可读口型，不必一开口就恢复正常。回现实接续原动作，不独立补演反应。进入、读懂、发展、退出都算时间，交代实际占屏与共时位置，保留有情绪作用的凝住、吞咽和静默。关键口型、接触与真实结果须能看清；两层抢读就重组，不往一秒塞完整奇观。一个机会选一种主表达，可递进多拍，不把备选累计全加，也不设幻想或高级镜头次数配额。

局部Q化/变景在picture或entry/exit中写明相对起止并对应实际镜号，screenSeconds记可选幻想的实际占时，源Q版即使没有候选也计入单元总预算；不伪造candidateId或新增字段来凑记录。匹配切回现实若真换镜位，实际拆镜并重算声音、幻想引用；若同镜形变恢复，写连续恢复而非隐藏一刀。

## 情绪机制正反例

以下只借情绪与形体机制，不移植角色、物件或源事件。若用秒数规划，它只是该段复杂度的示意，不存在3–5秒的统一上限。

- **肃穆场合反转后的荒诞解脱**：源文明确裁决中的误会解除，他仍想撑住体面；峰值是近景巨幅脸颊鼓起、笑意把脸撑出画框，双手忙着往回按，脚跟却轻飘飘踮起。原话与这次失守共时，形变可随余下喜悦延续。反例：因开场肃穆而只准微笑，或未有解围事实就擅自庆幸。
- **同一场合，反转却未解除痛苦**：源文只暂缓裁决，牵挂者仍受威胁；他试着抬嘴角，近景胸肩却化为薄瓷向两侧裂开，双手越拢越兜不住，明亮背景中身体独占痛感焦点。接回同次按胸与原有断续呼吸，不把裂开当真伤。反例：一听“暂缓”便套泄气弹跳，或把疼痛全交给黑暗背景。
- **不愿承认的惊愕**：源文已有证据在眼前、本人仍嘴硬否认；他用双手想遮掉所见，指缝像百叶窗合拢，瞳孔却越过缝隙越探越长，脸越躲越被自己的目光带向前景。Q版或原比例均可，嘴仍把源否认说完；回现实接同次遮挡又偷看的动作。反例：把求生恐惧、心虚遮掩与不甘否认都改成纸身折矮；或源已让他坦然接受，仍硬演否认。
- **轻盈浪漫的久别重逢**：源文已有车站相认与相拥；峰值让她延长的双臂横贯前景，手风琴般折起的站台在中后景被同一次拥抱收拢。原话从抬臂说到抱紧，回现实仍是这次相拥。反例：只有虚化泛光，再切回来重新抬臂说话。
- **真恐惧的失控**：原有威胁逼近，他攥紧支撑物、双膝发抖；主观中对方面孔扩成巨口，推拒的双手撑满前景仍够不到唇缘，镜头迎向他惊惧的脸。原有警告、呼喊或接触可穿过幻想，回接时危险仍在。反例：只有峭壁暗影、人物没反应，或幻象真把他咬伤。
- **严肃愤怒的顶回**：被压制却决定开口；峰值是本人半身前压占满画面，双手掰裂堵住口的陶面具，裂缝间终于说出口的脸成为第一焦点。脚跟顶稳、顶回原话与裂开同拍，回接同一次前跨。反例：通用喷火代替抵抗，或新增烧伤他人的战果。
- **强者从容的尺度反差**：源文已成立的挑战前，他不抬嗓，只捻平袖褶；峰值是巨幅手指与袖褶同框，布褶展开为山脊，又被这一小动作抚平。原话不中断，回接同次收指。反例：为了显强新增全灭敌人的真实战果，或把所有强者都改成怒吼。

Q版语境对照：

- **源未写Q版的嘴硬失守**：证据已使谎言站不住，他仍装镇定；短段Q版把挺着的胸膛和偷偷藏证物的小手拉成反差，嘴仍争辩，回现实接同一次藏手。不是原文没写就禁止，也不是先弹眼再哭倒的通用笑包。
- **源未写Q版的悲痛或不甘**：若缩小身形能表达被现实压得渺小，可以保留成年衣发、绷紧的脸和抗拒的支点，声音仍认真；若圆脸蹦跳会消解此人的痛，选原比例的形变、光影或真实表演。判断情绪作用，不以“严肃禁Q”或“Q必搞笑”代替判断。
- **源明确Q版的短OS**：在真正恼火或兴奋的词上兑现Q版，回原比例仍连着原话与动作；全句7秒不意味着7秒都Q化。若源明确整段保持某画风，不能擅改，先识别与预算是否冲突。

suggestedProposal只是已选的主表达起点，可改拍法或创造更贴切的机制，不是源事实、锁定方案或想象力上限。只有真实用户锁定才按userLockedProposal守约；若改变既定情绪功能/主体，须在关联范围一起修正，不假装原选择已实现。
