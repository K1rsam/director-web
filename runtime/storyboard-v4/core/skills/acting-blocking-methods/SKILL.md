# 表演与调度核心

此模块嵌入主创/整编，不是独立审批岗。先构想本拍由谁、以什么可见身体结果完成情绪峰值，再用人物要对谁做什么、遇到什么阻力组织到达过程；不要从“愤怒”直接抽一套握拳咬牙。

## 策略与幅度

- 按每拍、每个人处理刺激：此刻继续试探、转为遮掩、求援还是顶回，由新信息与阻力决定。日常基线要有任务和注意对象；关键词真正抵达时，节奏、重心或关系位置随策略改变，不把开场的严肃/从容一直演到底。
- 放大必须有看得见的身体结果：笑意撑开脸颊、胸肩带动双臂释放；维护权威时下巴还抬着，嘴角却失守；恐惧让脚掌寻找支点、躯干先撤而手仍抓紧。小动作也要让观众看见用力、失衡、停住或松开的变化，不能只写“猛然震惊”“用力挣扎”。
- 同样吃惊，遮丑者先挡证物，否认者欲退又探，求生者先找支点或退路；选符合此人策略的动作发展，不只换纸/铜材质。面具与泄露可相反，但不强制每场双重情绪；反转后也可能更疼、更警觉，而非全员同一张大嘴。不用幻想时基础表演也不减弱。
- 听者在关键词抵达时处理信息，不空脸排队；长句可在画外连续，画面给有效倾听或行动者的完成。先让关键接触、制动或关系动作以适合此人的幅度成立，再由反应放大其意义，不能用几张惊脸代替发生过程；也不因“主角优先”切掉真正属于听者的转折。
- 立场由动作关系决定，不仅看情绪形容词。握臂“催他下去”与“扶他落稳”会改变观看判断；保留源对象、主动性与策略，不默认温柔处理更合理。表演写可见发展：此前在做什么，哪句改变了它，随后选择什么；“没有误以为……”等解释放在必要边界，不占用正向表演。

## 动作有记忆

拿起→持有→移动→接触→松手只在发生变化时交代。主观段可由Q版本人、二维脸或变形身体承担表演，脸与身体可以就是幻想本体；不必每帧有写实真人，但身份、动作意图与情绪策略要可辨。夸张可跨镜、伴随原话继续，口型保持可读，不规定开口即恢复正常。回现实接原动作状态，源文的持物、伤势、真能力、知情、说者与声道不随形变改写。非人主体依自身耳、尾、爪、重心和避让表达，不强装人的五官或手。

接触前先确认双方距离、坐站和障碍：隔桌的手即使入镜也不自动够得着肩。可让靠近与前句话共时，在触碰前到位；不为补接近再演一次起身，也不先触碰后才补位置。Q版的变形动作回现实时同样接真实身体可达的相位，预算共用幻想层的40%时长上限。

## 正反例

好：想装作没被击中，嘴角硬提、下巴仍向前，手却把扶手攥紧；说话还在争夺位置。
坏：写“依旧高傲”，画面却无原因后退、垂头、全身发抖。

好：源文确认脱险，先前硬撑的肩背松开、身体一轻；下一句传来新的威胁时，脚跟重新落稳，手截住尚未放开的动作，重音转硬。
坏：一听好消息就全程弹跳，忽略下一拍的危险；或所有强者都冷笑、双手不动，所有开心都做同样星眼动作。

好：他已获知有利消息，听对方继续误判时先抿笑，笑气牵动颊与肩；轮到自己说话才放开，最后收笑作判断。Q版可放大这次失守，也可不用；重点是忍、漏、放、收各有语义触发，不是固定四步清单。
坏：只写“笑得很痛快、张开双臂”，四句立场变化都用同一笑脸陪读；或为多一个爆点，把对方每句话都切成惊讶。

源中的普通任务未结束、也未被新情境取消时，可用它的下一小步收反差：继续修补、收拾或核对不等于第二次超常出招。若这一回归承担情绪闭环，就把实际动作写进可见画面，不只“持物/看过去”加拟音；源已中断任务则不硬恢复。例子用于推演，不是菜单；四个专业只细化同一拍，不各加一轮反应。
