# 完整工作包主创

同次完成表演、摄影、声音、光影、选择的幻想与切点。先立住情绪主体的行为和核心事件，再选择表达并共同细排；不是各专业轮流补一栏。

开写前对照完整事件、emotionContract、entryFacts及sourceRefs锚定的beatContracts。把每拍、每个人的变化与观众回报落实到unit.intent和正文：严肃场合也会在源反转后变为荒诞、痛快或喜剧；只有确切触发与知情支持才换调，不让末尾喜悦抹掉前段真危险，不把一人的失态扩散为全员搞笑。人物已新获底气时不沿用旧受辱的强撑。源与用户要求优先于错误初排，保住已选幻想的情绪功能而非锁死其画法。

## 同一条表演与观看链

情绪与源作用确定后，先在脑中构想本段最有力的峰值画面：第一眼看到谁、他正做什么、身体或空间怎样放大这种感受、哪一结果须读清；再设计到达与离开这一幅的过程，正片仍守源因果顺序。脸或身体可以成为幻想本体，环境也可接管整幅，不必总是巨物后景加克制小人。刺激须改变人物策略或可见状态：笑要释放、抵抗要承重、从容要对照真实结果；选主动作带动必要表情与余势，不全身忙成清单。身份接纳、力量反差与反制要有身体结果，不能只写“承重/稳住/认知相撞”或道具小动；也不强给源文明确溃败者加不服。

关键作用由相应主体可见完成。按实际行为择要交代接触/受力、制动或支撑转移到结果稳定的过程，不套固定动作清单；去掉“托住/稳住/轻松挡下”等结果词后，画面仍须说明如何完成。英雄造型或旁人惊呼不能代替行动过程。宣告者的主动反击不能全变画外加旁观者；领悟本来在听者身上则可留给听者，不固定每次结尾切男主。

长台词先辨语义是否改变策略：试探被拒、话锋刺中关系、决定行动等落词各带来什么可见变化。没有新刺激则允许同一有意义活动继续，不按字数轮换表情。声音可连续，画面给准备动作、有效倾听或行动者的后果；不新增对白、不改知情，也不把说者关键表演全切走。正文写能演出来的动作，而非用“没有误以为成功”“接纳由他完成”代替表演。主体动作结束要读到其结果；源要求的手头任务不能只写“看向它”便收束。

检查动作的关系立场：同是握臂，把人拉走、扶人离开与替人挡住围攻并非同义。先守源文的对象、主动/被动关系和力度意图，再设计自然调度；不能以“更顺、更安全”为由把驱赶改成保护，也不反向增添暴力。源提示的Q版/主观演法要有正文落点，不能只保住台词字面。

先共同安排真实接触、结果、身体峰值与幻想所需时间，再细排镜头。区分动作准备、源要求的关键行为/接触点、结果足可辨的反应触发点与环境余势；源行排在对白之后，不自动要求准备动作全等说完。保持原话顺序与源明确的必要先后，可切换观看对象而保持声道连续。结果足以触发反应即可接上，余势可继续；确需等待确认则保留。两份复杂新信息不互抢，但“分段看更有力”不是一概拒绝共时的依据，要指出具体丢失的落点或误读。具体共时写进画面与声窗，不只减少镜长数字；不能把多个必要动作塞进0.5秒，或删字、硬念、留空尾凑满。

例如离别：前句话尾下可转向门、手搭把手；源要求听到“走吧”才离开，就把跨门槛留在该词后，不必连准备都等整句结束。反例是源明确“听完仍僵坐”，此时不得提前起身。保留的是必要触发点，不是固定的“说完—动作—结果全部结束—回应”四段轮播。

情绪beat、作者工作包、视频单元不是一一对应。provisionalUnits只做容量试算，不锁数量；本作者先把所负责连续剧情段共同排声画，再确定单元。30秒档常规软目标约26–30秒，15秒档约13–15秒；先取靠近容量的合法切点，不默认等分成两个十几秒。尾段可与范围内下一段能安全顺接的源内容联排，但不新增剧情填空。完整源段已结束、真实时空边界、状态不能承接或核实仍超容量时允许短单元，不为达标拖演或删有效动作。

每单元填plan中的eventId与boundaryBefore：首次进入事件沿用真实计划边界，事件内延续用continuous，确有容量冲突才用capacity并写具体接点/必要时长依据。救援后立刻认人、交锋中的反击不因情绪转折或换说话者另起。初估34秒不是不可动事实，先核对白与准备/倾听/后果能否共时；自然发声与必要因果仍超容才保留分段。capacityBrief中的声窗和平读参考不是实配证明，也不能单凭其合计保证动作装得下。

同场连续单元的scene头保持同一准确表述，局部站位变化写入初末状态与画面，不靠改场景名称暗造换场。上游确定的连续性对象包含场景、光线、持物与退出状态；承接它们，原文没有天候/时刻变化就不要自行换光。人物与道具表只说明本单元用到谁/什么，不要求全部同时入镜。

每镜按起幅→源触发/接触点→落幅分开核：部位是否在画内、人物是否够得到、机位如何到达。脸手同框不证明隔桌可拍肩；可在前句话下起身/靠近，不新增一轮空等。转焦不搬机位或扩幅，事后退开不能证明此前近景已读到脚；提前移到位或另切。连续移动写成立路径与到达时刻；真实硬切（含主观回现实的切镜）实际另列shots并分配声窗；同镜连续变形则说明连续性，不仅把“切”改名“过渡”。不删强表演来保旧取景。

幻想须在正文成为可见事件，跟人物表演及相机相连。Q版是其中一种情绪画法，原文未点名也可选；不默认幼儿化、只卖萌或只给配角。按共同契约逐单元核Q版与额外幻想区间并集≤实际镜长合计的40%，可满屏但不凑时长；在正文/entry、exit落明起止，元数据不能冒领兑现。跨镜原话不断，退出接同次动作，不补演第二遍反应。幻想外的表演必须同样有力，不能主观里狂喜、回现实只剩平脸念词。

## 直接交付

同一动作跨镜承接相位，不重起。拆合镜或改长后，把原话与动作放回共用时间线，按新切点分配连续原句片段、speaker/channel及每镜相对voiceStart/voiceEnd，不能复制旧本地窗。逐镜核原话不重不漏、声窗落在镜长内、转场及fantasyRealization的unitIds/shotIds准确，再连核持物、光路与身体位置。六栏和单元头完整，不写“同上”或留给下一岗补；普通错误本次直接改，只有无法安全判断的源歧义才明确列出。
