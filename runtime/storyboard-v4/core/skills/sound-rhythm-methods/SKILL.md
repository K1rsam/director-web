# 声音与时间核心

原话、说者、源声道先准确；源句可跨镜/单元连续承载，字句不重不漏。画内变画外不是变OS，内心声音不让未知情者反应。

## 共同时间

估正常语速和真实事件容量，镜头/动作/听者反应能同时发生就共时，不能各算一套再相加。给出重要重音、音强、语气或气口即可，不强填十三项声音参数。

拆合镜或改镜长时，先在共用时间线排原话、必要气口与动作触发，再按新切点分配连续原句片段与speaker/channel，最后减去各新镜起点得到相对voiceStart/voiceEnd。未跨切点例：共用线上8.4–10.0秒发声，新镜从7.0秒起、长3.5秒，本地声窗为1.4–3.0秒；不能复制旧镜的本地窗。

声段跨切则按发声进度把原句连续切片给相邻镜，每字只归属一次，声音与气口接续，不让两镜重播整句。有发声镜核0≤voiceStart<voiceEnd≤镜长，并连核原话、speaker/channel、动作触发与转场；装不下就重排切点、共时或镜长，不吞字、催读或把voiceEnd机械clamp到镜尾。文字估窗不是实际配音证明。

先按完整句的语气排声，再分到各单元；不能前半沉稳铺陈，尾段突然挤成快读，却仍标“压低、停顿”。计字/平读只用于发现风险，不设统一字速裁判。叹气、欲言又止若有情绪功能须占有真实时间，可与准备或倾听共时，不一律加长，也不把开口前0.1秒当已经完成整次叹息。

删除的是无信息空等：睁眼确认、再揉眼确认、再喘气再问若只做同一件事，应合并或共时。保留悬念、憋笑失败、被截断呼吸、决断等真正有意义的停顿。

声音可在危险仍压近时先介入，或跨切维持压力；不要等前一表演彻底结束才接下一声。Q版/幻想可伴随原话发展，占屏不等于净增时间，但须遵守共同契约的40%并集上限；超预算改视觉方案或回现实续原话，不加速、不吞情绪停顿，也不把进入/变化/退出挤成一秒。源反转改变情绪时，声音在对应关键词换重音或留白，不沿用开场腔调。源无撞击声不补低频；画面放慢也可保持对白正常。

## 正反例

好：对方问到关键身份时，镜头转到听者，原句不断；听者只反应，不做说话者口型。
坏：每一句都拍完说者、停一秒，再切人吸气，最后又靠加快句尾凑30秒。

好：制动后短暂衣摆回落；多个镜头后衣角仍动，明确由持续风/火流驱动。
坏：十余秒后仍称“刚才那次停步的最后余动”。

合成平读仅作参照，不能当演员/视频实测。长段超载先重新共时、细排或自然分包，不删原话、不盲目缩成15秒。额外时长须换来可见事件或情绪推进。
