# 直接整编与联修

读取本范围原文/关键前情、共同emotionContract和完整现稿。不能只相信初排或作者的“已兑现”记录。一次给可采用改稿，不发明审核员—批准员—执行员循环。

## 核查次序

1. **源状态与演法**：逐项对照入口事实与最近原文；已收起、拿起、受伤、知情和正文是否同一状态，不根据想拍的效果反推事实。核源明确Q版/主观提示是否真正出现；台词字面全不代表演法已保留。拉离、扶离、阻拦等动作的对象与主动关系也须守住，不能无依据替驱逐者增写保护立场。
2. **情绪与主次**：逐拍以当前原文的sourceRefs复核beatContracts：此前状态、新刺激/获知/决定怎样改变底气与策略，谁完成本拍回报？不让初排的“严肃”标签或末拍基调覆盖全段；源已支持反差夸张就兑现，同场不同人可不同调，未转的伤痛与危险仍有重量。主动轻蔑痛快不能因早先受辱退成“强撑/故作庆祝”。核关键落词时谁主导画幅、身体/关系变化是否可见；剧情和表情方向对仍可能力度不足，不能以道具小动或旁人惊叹替代主体峰值。保留有效功能，不保护错误画法或以样稿为力度上限。
3. **观看、可达与切镜**：按起幅→触发/接触点→落幅分别核画框、物理距离和相机路径；脸手同框不证明隔桌可拍肩，“中景”也不能同时保证完整双脚。先改站位接近、起幅或到位时点。核画内外标注与说者是否同框开口一致，转焦不自动成为画外。所有独立硬切（含幻想内外匹配切）实际另列shots、分镜长与声窗；同镜连续变形须真有连续路径，不只换词藏切。保住核心行动与身体峰值。
4. **共同时间与表演发展**：按长句里的新信息检查人物策略是否推进；同向再看一眼、重复绷肩或心理说明不自动构成新信息。声音连续时可给有效倾听或行动者，不强制每镜主角反应。把准备、倾听、后果放回同一时间线，收空等而非削弱情绪落点；跨单元同句不因尾段难塞而突然催读。先读完整句，再分局部声窗，估窗不是实配证明。
5. **幻想作用与预算**：关掉仍看见核心行动，打开又发展什么身体/关系变化？去掉“稳住”等结果词检查关键行为，不要求每个小动作拆步骤。Q版与其他幻想同一岗位择优，不检查“有无Q版”来凑数；不能只在私下兴奋处做大图，却把公开反击演平。依共同契约逐单元核实际出现区间并集≤40%，含源Q版，重叠不重复计；进入至退出全算，满画幅仍允许。核正文与entry/exit、screenSeconds一致，不只相信元数据或拿整集均值掩盖超额。

按实际镜长区分动作准备、源要求的关键行为/接触点、结果足可辨的反应触发点与环境余势，再走开口顺序。源行排列不自动禁止声画共时；不能把保留关键因果偷换成“说完才准备，全部余势结束才回应”。例如审问时可在上一句尾下伸手到证物旁，源要求听到关键词才翻面就保留翻面的时点；若源明确此前双手被按住，则不能提前伸手。可触发反应的结果已出现时，余势可与身体变化共时；必须等待确认的因果不抢。若开口前确须完成落脚、受创、转头等多个结果，不能塞进0.5–1秒，再用完整声窗假装合格。同一动作在画面/演法栏各做一次也可能是重演。删空等，不删疼痛、抗争或胜利的落点。结束闭环须有源支持的可见动作结果，不把“又看向某处”当作已完成行动。

将缺陷落到实际镜号和源依据，直接联动六栏/镜长及相邻单元修好；旧契约失准则据源修正文，在已有revisionNotes说明。无需改动就沿用，不为必须修改而换同义词；“没发现问题”不等于可跳过上述检查，也不是成片通过。

事实修复不能靠补原文没有的能力重启、痊愈或获知来圆旧稿；普通自然调度仍可设计。若此前已收起护罩，现稿误把它写成常亮，就更换错误画面或主观意象，不私自补“再开启一次”以保存旧特效。能力受压可以通过可见表演与明确主观体验表现，不能因此新增客观施法事件。

## 整段重排与容量

初排、工作包和情绪beat都不是视频单元的硬边界。先通读本范围连续剧情段，再核相邻单元的eventId、场景、末态→初态和真实边界；同场同一时间、状态可顺接的关联小事件可联排，不能只看已有切分。30秒档让常规单元多数尽量落在约26–30秒，15秒档约13–15秒，均非硬下限。优先找靠近容量的合法切点，不默认把超容段平均切成两个十几秒；不足尾段可与下一可顺接的源内容联排。源已结束、真实时空转换或无法安全承接时可短，不加空白或新剧情填。

收到capacityBrief时核各单元、全范围时长及声窗；平读时长只是参考，不是实配或动作可执行证明。原稿的31.3/34秒也是导演估值，不是必须保留的源事实。先重排可共时声画，保住必要因果与身体峰值，再判断是否仍超容。连续段能自然装入容量时，实际输出合并后的unit，不只在revisionNotes说“可以合并”；真正仍超容才分段。约23.5秒的救援与立刻认人可作为一个完整单元，已收束则不填到26秒；次日换场即使共18秒也不强合。

增时与缩时都核收益和代价：在已有revisionNotes记录实改坐标、旧→新时长/单元数、怎么共时或删去何种重复，并以preservedFunction核原有的身体峰值、立场和情绪落点仍看得见。不能只审增时不审压缩，也不要求未改镜逐条写检查报告。把离台、松手、换人、摊手、转身列在1.8秒里，不等于已经拍清；应区分可并行背景与需先后完成的主体行动。共时不成立须有源等待、物理条件或具体抢读依据；画面换主体不必截断声音。无实配明示估算，不用少算气口、快念句尾或加空白凑档；先重排邻近连续内容，真装不下才保留有理由的短尾。

重排保留源动作、有效表演、原话、声道、光影与先后落点，去掉重复确认而非照抄旧镜表再改总秒数。拆合镜后先把原话与动作放回共用时间线，再按新切点分配连续原句片段及speaker/channel，逐镜从新起点重算相对voiceStart/voiceEnd；跨切不断声、不重放整句。核原话片段—声窗—动作触发—镜长—转场—fantasyRealization引用一致，有发声镜满足0≤voiceStart<voiceEnd≤镜长；不复制旧本地窗，不以吞字、催读或机械clamp过关。

合并初态取最前、末态取最后，人物/道具取并集但不强迫同镜。现稿若带segments，将其有效光影/状态差异落到对应shotIds，不只留首段头。同步更新fantasyRealization的unitIds/shotIds与内部段落衔接。每个保留边界写boundaryBefore及具体理由；状态冲突依源联修，不靠continuous强合或new_event掩饰碎分。不得为凑30秒拖气口，或为保留初排包数加速念词。

好：发现开头设物品已收起，后景却持续发光，改对应画面、光影、入出状态及幻想入口，不仅在备注写“以源为准”。
坏：补齐一个声音字段就宣布没有源冲突；或为了空间简单把强表演改成微笑，并删掉原本的关系反转。

改法可以不同，源话、事实和用户情绪要求不掉。按输出契约返回完整关联范围、具体已修项与未解决项，不用自评分放行；代码检查、专业文字评审、实际配音/视频和用户认可分开。
