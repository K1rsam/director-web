# 情绪统筹与弹性初排

通读给定本集和前情，先判断每拍人物的底气、策略、知情变化与观众回报，再以连续剧情段统筹整集容量。情绪beat是段内的转折，工作包是同一作者的负责范围，视频单元只是所选15/30秒的承载容器，三者不是一一对应。

沿“刺激→应对→真实结果→认知/情绪落点”找events，用sourceRefs、sceneKey与boundaryBefore记依据。同场同一时间、状态可顺接的关联小事件可组成一个连续剧情段，交同一作者并保留内部各beat；不因落点、换说话者或手头任务变化就另起new_event。首项episode_start表示本次制作源范围开始，不是全剧开场；独立事件已收束且无关联后续、真实时空转换或无法安全承接才另起边界，段内延续标continuous。每个事件写覆盖整条变化的emotionContract，每包用eventId归属。事件超过容量仍归同一作者，内部可有多个单元。

在既有emotionContract中分清整段核心回报与各拍反应：change按sourceRefs写刺激/反转和各人物策略变化；landing写谁凭什么改变了局面、观众应记住的身体/关系结果；retain保住让该结果可信的可见行动证据与必要闭环，而非只列台词名词。最夸张的反应者和末句说者不自动拥有整段高潮，也不强制主角每镜露脸。与其只写“帅、稳、厉害”，应说明哪一关键相位让观众读到他完成了作用。强者可安静，喜悦可含泪；力度服务当拍情绪，不套身份模板或把样稿当上限。

逐拍核entryFacts与当前原文中当拍已发生、各人物已知的事实，再提出画法。新的得势、获知或决定可使严肃转成反差夸张；不能因开场严肃就整场禁喜剧，也不能因更早受辱把主动轻蔑痛快写成“强撑/故作庆祝”。同场不同人、前后不同拍可不同调，切换须有源锚与相应知情/策略变化，不把一人的释放套给仍在伤痛中的他人。事实来源、计划设计分开；持物/伤势/知情须顺到下一包。确需另一完整事件的出口才能写后段时标dependsOn，不让两包各自假定站位。

幻想候选挂源锚，以emotionPurpose说明加强哪一回报。先比较它对人物策略、关系反转及观众理解的帮助，再选形式；不是哪里容易做安全的主观空间就优先给哪里。私下获知与公开行动可有不同峰值：内部兴奋不能耗尽公开反击的表现设计，后者即使不加幻想也要有有力的主体行动。源要求的Q版等写入相关retain；额外Q版不要求原文点名，归入同一幻想候选，不另设层。

候选联合预算遵守共同契约的每单元Q版与额外幻想并集≤40%，不是每个候选各有40%；初排按预计实际单元时长留量，最终切分后重算。proposal只给本版主表达，不堆备选；screenSecondsRange含进入至退出，extraSecondsRange只记不能与原话/动作共时的净增时间。all落实所选机会而非平均分配高潮；同一情绪可共用表达，不能为了all把过多独立变形塞进短窗。推荐可不推荐，off不设计额外候选但保留源明确Q版、法术与梦境。提案不是源事实或用户锁定，主创可用更合适的画法。

先对每个完整连续范围做一次声画容量统筹，再给自然发声、必要事件的区间与合法接点，不锁细镜。区分动作准备、源要求的关键行为/接触点、结果足可辨的反应触发点与环境余势；源行排列不自动要求全部串行。守住原话顺序和源明确的必要先后，可把准备放到前句话尾下、反应放到结果已可辨但余势未尽时。别把所有幻想都估成净增零秒；独立看懂的事件要预留容量，能共时的也不能抢掉主体。少量方法卡按需要选；普通一集无须加载整库。

30秒档让常规单元多数尽量落在约26–30秒，15秒档约13–15秒；这是软目标，不是硬下限。按整段联排结果给出本版provisionalUnits的实际sourceRefs分配与靠近容量的合法接点，不先每beat各列一个短区间，再用“后续可合并”把联排留给下游。未实配可标估算区间，但仍须完成本版容量安排；provisionalUnits可据证据调整，不是最终数量指令。不默认等分成两个十几秒，不足尾段可与下一段可顺接的源内容联排。源段已完整结束、真实时空边界、不能安全承接或核实后仍不可删的必要时长，均可保留短单元，并在对应边界理由写具体依据；不能凭空加戏、拉空白、催读或削弱有效动作凑档。收到capacityBrief时把声窗/平读时长仅作参考，不当实配结果；导演初估超容也不是源事实，先查能否共时，再确认必须分段。

边界例（用于判断，不是题材或画法上限）：

- 救下人后立刻认出救命者，约24秒且本段已收束：一个事件/作者/单元；不拆成两包，也不凭空补到26秒。
- 首演前被告知停演，随后源文证实通知拿错：团长的惊痛可在获知后转成羞恼的喜剧破防；若停演属实、痛苦未转，不能仅因换Q版就演成笑话。前后仍可归同一事件/作者，不因换调拆包。
- 一次告别初估34秒：先核承诺与准备离开能否共时；只有自然发声和不能共时的必要动作仍超容量才分段，不把初估直接当拆分结论。
- 门外救援已收束，次日室内审问：两个事件保留时空边界，即使相加不足30秒也不为了满额合并。

输出按计划契约；原话/动作源行必须有归属，元场次无需独占镜头。数量弹性不等于任意拆碎；只在自然边界拆包。保持每段不同的情绪作用，不复制一个强弱曲线贯穿全篇。
