# 摄影与观看核心

先确定情绪峰值的观看关系，再写起幅、触发、相对人物的路径/速度、落幅和新增信息。谁占主要画幅、谁在近处施压、背景留下什么，要具体可见；术语不能代替结果。

## 主动选择

人物前压可由镜头让位或迎近放大；静止可把拒绝/重量压在画框里；转焦可以把观看权交给听者。选与本拍相称的方式，不所有镜头微推，也不把静机当唯一安全选项。

主观域允许夸张透视、推拉变焦、尺度跳变或2D/3D混合观看，按该拍情绪与人物动作选择，不因现实域的空间连续要求全部退成微推。写清可见变化和回接地标/动作相位；形式不自带喜剧性，也不等于人物获得真实能力。

重要脸部转折须有足够大且不被遮住的脸；Q版身体、前伸手或幻想景观都可成为视觉主块，不设统一占幅百分比。巨物要有明确比例参照及前中后层，不只写“百米尺度清楚”。只保住人脸并不等于人物主导，巨背景也不等于幻想有力；依每拍情绪和源反转改变视觉主次。两种任务互抢时调整取景/转焦/切点，不让大全景小人承担细眉动作。

## 可见性与连续性

先有稳定地标与人物朝向，再写画面左右。逐镜按起幅→源触发/接触点→落幅，核该刻相机位置、画框范围、必须读到的脸/手/腿/受力对象及遮挡。背后读侧脸须偏侧角度或转头；半身不能证明脚下接触。退机若在动作后才露出腿，不能追认此前已见；应提前移到位、改起幅或另切，主观域也须交代画幅怎样变开。不用“始终清楚”或光照词代替核对。

可见与可达分开：同框看见手和肩，不代表人物能隔桌触及；全身支点需中全景/全身画幅或接触专镜，不给“中景”同时塞完整双腿。说话者仍同框开口，转焦到听者并不自动让台词变画外；若裁出说者再转声道，应写清裁出的时点。

连续移动写相对人物的起止位置、路径和到达关键点的时刻，换侧/绕过遮挡须有可成立的过程；转焦只换焦点，不搬机位或扩幅。实为硬切就另列shots、分配镜长和转场，接同一次动作相位；只在摄影栏写“切到另一机位”不算完成拆镜。取景冲突不以删核心行动、身体峰值或幻想强度解决。

这也适用于Q版/幻想进出：连续形变可保持一个镜条目；从主观手部匹配切到现实侧脸是两次取景，要实际分镜。不能只把“匹配切”改成“回接”避开拆镜，须交代到底连续还是切换。

演员与镜头并发时写在同一时间进程，不让摄影随后追演。动切接同一次动作相位，不重做起势；短镜按首次识人、信息与动作负担判断，不机械禁2秒以下。

## 正反例

好：在侧向跟拍中角色离开柜台朝门口移动，前景门框掠过后露出挡路者，镜头在双方距离成立处停。
坏：角色走完才“镜头跟上”；或绕了一圈仍没多给任何关系。

好：从人物侧后给其视线目标与背影，再切侧前近景读反应。
坏：人物正看北侧目标，相机在其北侧拍正脸，却要求北方目标仍在他的肩后。

高级手法不设次数配额；清楚并不等于平淡，复杂也不等于更有冲击。
