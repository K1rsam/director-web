## 本轮采用的推荐选择

- 新单集默认最多8条请求记录、600,000已知原始Token；500,000提示留意，不因此重跑或暂停。停止的是下一次派单，在途回包仍保存，不是账单硬封顶。
- 新共享预算按所选集数推荐：次数 `max(40, 6×集数)`，Token `max(2,000,000, 450,000×集数)`；80集为480条记录/36,000,000。四组共享，不各建预算；沿用旧账本时不清零、不自动调限。
- 普通6.1 Sol、中档、不用Fast；幻想默认推荐加入。既有采用稿、冻结请求、停止线及显式配置不被改写。
- 继续复用现有只读重取、局部返修和实际承接核对；相同问题无进展有上限，不用扩大预算掩盖循环。
- 有充分来源依据的整理、推荐读法由执行Agent在用户委托范围内处理并留证。不能把AI输出伪装成用户已逐条确认，不能自动豁免原文事实、锁约定或新UNKNOWN费用；确实无依据的重要取舍仍保留安全停点。
