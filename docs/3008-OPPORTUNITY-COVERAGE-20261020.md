原后续输入与输出 schema 只提供/接受已选候选；choose/confirm 只能选既有候选，replan 另调模型且不适用于已有正文。因此仅提示“发现后更新计划”会是假入口。

新普通 author/full finish/delta finish 的同次正常回包可有 `fantasySupplements`；仅纯自动 recommended/all、无逐项/单元 override、确认指纹或待复核项时允许。新机会必须位于本次 sourceRows（不是 contextRows）、归属同一完整工作包、无未知/重复/覆盖旧项，且在本次实际新写镜头兑现；delta 必须随完整替换组，不能借保留旧镜或 not_realized 冒领。现有源、台词、声音、时长、承接与反馈校验仍全部运行。全通过才在同一采用事务 append 计划、默认选入及真实自动来源；无效回包不改计划/选择/已采用稿，原 output/raw 留存，未自动补买。
