## 二、Mac 获取与启动

需要 Node.js 24.x、npm、Git；CLI 模式还需要 Mac 本机安装并登录 Codex CLI。Python 3 用于保真工具。CLI 使用 `gpt-5.6-terra / medium`；API 模式仍走现有供应商适配，不应声称已切换为 Terra。

```bash
git clone --branch handoff/3008-stage1.5 --single-branch https://github.com/K1rsam/director-web.git director-web-3008-handoff
cd director-web-3008-handoff
npm ci
cp .env.3008.example .env
```

编辑 `.env`，填写自行生成的 `DIRECTOR_CREDENTIAL_KEY`（至少32字符）和 `TEST_ACCOUNT_INITIAL_PASSWORD`。保持独立数据库和 `director_session_3008` Cookie 名。然后：

```bash
npm run prisma:generate
npm run database:migrate
npm run accounts:seed
npm run dev:3008
```

打开 `http://127.0.0.1:3008`，使用 `tester01` 和自己设置的密码。首次创建的是空库，需导入自己的剧本。不要复制 Windows 的 node_modules、.next、CLI 登录文件或绝对路径配置。

若已有本分支克隆，先保存本机改动，再 `git pull --ff-only`。已有项目数据通过私人数据库备份迁移，保留原加密密钥；不要将数据库推送 GitHub。详细迁移见 [Mac 数据迁移](LOCAL-SETUP-MAC.md)。源码可以在 Mac 直接阅读和安装，但本次没有 Mac 实机，不能承诺零配置运行。
