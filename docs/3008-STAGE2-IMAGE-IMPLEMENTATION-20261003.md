# 3008 第二阶段图片工作台

本地独立分支 `local/3008-stage2-images-20261003`，基于官方交接提交 `cc3bf6316cc9f40819f47a72a46432d6a8731aaa`。旧目录和数据库保留。本文件记录当前实现，历史测试没有改写为成功。

## 使用

打开 [3008](http://127.0.0.1:3008/login)，沿用原3008账号。进入第二阶段，选择资产 → 编辑并保存提示词 → 选择出图方式 → 生成图片。返回的图片先作为候选，用户选择参考图并采用设计后才供后续制作使用。

第二阶段不再要求填写“制作集数”：浏览显示完整资产目录，服务端制作范围由资产的真实生产集计算。桌面左侧是固定大图网格，右侧是提示词、比例、画质、数量和生成。单张资产仍占一个网格卡片。项目画风、资料、采用与历史折叠；1366×768也直接显示提示词和生成按钮，手机单栏无横向溢出。

当前出图方式只有 **Chrome · ChatGPT 网页** 已接通，自动回传目前限定每次1张；多图未验收，服务端在创建前拒绝，手动交接原有多图能力保持。API和CLI明确标为待接入并禁用，不能误称已支持。完成一次连接设置后，日常生成只点击“生成图片”；它同时创建当前任务并启用执行器，不需要先启用、再创建、再刷新。

## 浏览器连接和启动

`start-3008.ps1` 启动本地工作台；`start-image-browser.ps1` 启动回环地址53179的Bridge和常驻执行器。两者独立于Codex进程，关闭Agent不会主动停止。关闭Chrome、电脑或后台进程后需恢复启动，没有配置开机自启。

本机采用 [DrA1ex/chatgpt-bridge](https://github.com/DrA1ex/chatgpt-bridge)，固定提交 `671815e1939db9effb556ea7ef67673fc21e4121`，Bridge6.4.0、Chrome扩展2.4.5。通过本地HTTP/扩展通信驱动网页和获取原图。内置浏览器Cookie不会自动迁移到Chrome。

首次在使用的Chrome里加载扩展，登录ChatGPT，访问 [连接设置](http://127.0.0.1:53179/setup)，按页面完成Bridge连接。用户已完成本机连接。后续保持浏览器和连接标签页运行即可；诊断和连接令牌放在连接设置，不进入提示词或3008前端。不要发送Cookie或令牌到聊天。

启动校验固定版本及补丁整体哈希。未知源码漂移停止，保留原始文件备份与安装回执。内容脚本更新只在空闲时重载扩展，使用 `reloadTabs:false`，不批量重载用户的其他ChatGPT会话。

## 任务与原图

- 任务绑定项目、资产/子形象、真实生产集、保存的提示词、画风、设置和来源链版本；派生形象必须绑定直接来源已采用原图。
- 全局一次只执行一个网页任务。新任务自动打开并选中独立任务标签页，固定launchToken/sourceClientId，不调用Chrome窗口聚焦；浏览器窗口可留在后台。默认active=true，减少非活动标签页对上传、输入的节流；`IMAGE_BROWSER_FOREGROUND=0`仅用于后台压力测试。提交前持久化journal，只有一次 `POST /turns`。回执丢失、断线和重启只查询原任务，不重发。
- `action=generate` 明确标记 `dispatchMode=CHROME`。旧 `action=create`、未标记任务和手动等待队列不会因启用而自动发送。
- 校验canonical生成画廊、requestId、sourceTurnKey、sourceClientId、会话URL、READY、MIME、数量；sessionId仅在公共投影存在时额外核验，显式非生成图始终拒绝。
- 单图原生证明核验当前分支唯一用户、实际提示词SHA、完成助手和文件指针，验证真实PNG/JPEG/WebP、原图字节、重新读取的分支及页面/节点/租约身份。后台0×0图片只能在完整证明后使用原生下载结果。多图的后台原生回退尚未实测，不宣称支持。
- 原图落盘、下载、导入后均核验SHA256。Bridge内部base64只由程序传输，不进入模型上下文。原图保持原字节；工作台使用最长边640px的WebP预览，点击查看、下载与后续引用仍使用原图。预览压缩不改变原图。
- 私有原图接口需要登录及项目权限。候选回传不自动覆盖旧图、不自动采用设计。失败、中断、来源更新和晚返回保留历史。

备用 `director_images` MCP供手动执行交接；重启Agent后加载。手动导入标记 `MANUAL_IMPORT`，不能冒充网页自动回传。任务原图目录为 `runtime-3008/chatgpt-images/<jobId>/originals`，配置、令牌、私有数据库和运行产物不提交。
