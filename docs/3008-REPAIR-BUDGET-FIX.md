# Q1 格式修复预算故障修复

日期：2026-09-12。适用独立 3008 分支，保留 P1–P4 当前流程。

## 故障和根因

一次 70 集测试中，F2 已保存全部资料；Q1 首轮按精确请求规划选择 1–50 集，实际请求 175,712 字符并已收到模型返回。校验停在 changes.sceneSplits.1.cuts.0.timeOfDay：模型用 null 表示未声明，拆场可选字段仅容许 undefined，而普通场景字段已容许 null。之后格式修复将完整原输入与完整返回再包装，达到 207,947 字符；加 24,000 输出预留，超过 200,000 应用字符预算。第二次请求未发送，不能据此推断第一轮没有调用模型。

## 修复

- 拆场四个可选文本字段的 null 与省略等价；不补时间、不改台词或动作，不改变原始响应。数字、布尔、对象、数组仍拒绝，必要行号与逐字锚点继续严格验证。
- 已解析的格式错误使用 FIELD_REPAIR_V1 局部字段包：仅包含程序定位的错误路径、原值与约束。专用机械修复系统提示传入真实 provider，沿用原模型和强度；不发送完整原稿、资产目录、原返回或全量创作 schema。
- 补丁只合入允许路径，禁止越界、重复、原型路径和清空既有数组，正确字段从原响应保留；随后仍进行完整校验。旧整对象返回仅取已授权路径，兼容历史恢复。
- 语法完全无法解析的返回仍使用有预算拦截的旧修复包；本轮不声称任意损坏 JSON 都可自动恢复。
- 预算提示明确区分“本次请求未发送”和历史模型调用，避免让用户误判 CLI 未接入。

## 验证与恢复边界

通过 34 项调用与费用保护回归、新增大首轮/小修复/已付费恢复/非法路径/语法预算测试、可选空值和原文锚点回归、无效修复路由回归、TypeScript 和生产构建。构建保留 4 条既存 CLI 动态路径追踪警告。

真实失败数据库的隔离副本回放：1–50 集已付费结果通过完整控制器校验并直接恢复；只对 51–70 集产生一次模拟后续调用，输入 105,638 字符。F2 没有重做，真实模型调用为 0。副本最终在后续内容待办处主动停止；这不是全剧真实模型重跑或内容质量验收。私人副本和响应未入库。

本机 3008 服务更新后，原项目保留历史失败记录。刷新页面后点击继续整理，会先重新校验并复用已付费返回，再处理剩余范围。无需重新上传原稿或重建项目。单纯刷新不会把历史失败记录改成已完成。
