# 3008 剧本接收与暂停恢复 V2

2026年10月11日。本记录补充[按集证据供给 V1](3008-EPISODE-EVIDENCE-SUPPLY-20261011-V1.md)，不覆盖历史结论。修复范围是源文识别、标准稿编译与第三阶段独立接收，不调整创作岗位、SKILL、模型或预算。

## 暂停原因

《乌龟》80集资料已经保存并核对，最终接收检查却把第1集正常的“柳凡 os：”当成身份不明的冒号行，任务历史因此留下 PARTIAL。这里的 os 是声道，不是人物名，也不需要用户做创作确认。只重跑这一集或提高用量上限不能解决这个问题。

修复后的当前状态为：80/80集可读、80/80集已核对、资料完整、无接收问题、无继续阻塞，下一动作 NONE。实际3008页面已显示“资料已整理”。旧暂停记录保留为历史，不篡改成另一份执行回执。

## 通用接收规则

- 人物与 OS/VO 之间允许普通空格、制表符、不换行空格及全角空格；大小写和换行格式不改变含义。括号表演提示前后的声道按原位置独立拆分，不把 Carlos 等字面姓名截短。
- 原文明示的人物、职业、群体及编号说者不依赖 AI 资产库是否收录同名条目；保留完整源标签，不擅自合并身份或生成别名。
- 有独立人物依据的有限裸表演提示可拆分，例如“王东憋笑：”。人物本名或带括号的身份声明优先，不因形似提示而缩短。
- 明示弹幕、字幕、屏幕文字进入画面文字，不新增说话人；独立省略号不追加进上一句台词，引号内省略号仍属于原话。
- 系统播报中明确的任务目标、任务奖励等字段保留为同一句；有明确出声提示的条款朗读保留内部冒号。默读、否定朗读和尚未出声不能冒充已说出的台词。
- “剧情梗概研究员”“操作指南守卫”等资料标题不会因像职业或带 OS 而自动成为人物；只有源文明示的同名人物声明才能建立对应身份。

这些规则同时进入标准稿编译与第三阶段独立校验。双方仍核对原文切片、UTF16坐标、字段归属和完整覆盖，不能只让前端显示通过而让下游继续拒收。

## 恢复与费用边界

当前完成状态依据现有原文、有效资料、资产登记和未解决问题计算，不只看历史任务写过 PARTIAL。已有资料通过免费重核后直接可用，不再为旧格式错误重新生成整套资料。

本轮未重新派生产任务、未调用真实模型、未改写用户业务库、未增加预算或调用岗位。临时库测试使用模拟回包；历史费用仍按原回执保留，不能由免费重核推断整部项目零消耗。

真正的原文冲突、无法归属的对白、多个冲突声道、缺失来源、未知派单结果、正在执行的任务和实际预算风险继续保留保护。消除误暂停不等于取消这些检查，也不承诺任意未知编剧格式永远零问题。
