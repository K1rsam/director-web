# 第二阶段按需准备 · V1

日期：2026-10-02。承接三阶段闭环计划及资产方向说明，追加本轮实施记录，不替换历史结论。本轮没有真实模型调用、生产数据库写入、后台任务派发或Git提交/推送。

## 下一步的准确含义

第一阶段完成后，不再自动生产全库外观事实、逐资产提示词或图片。第二阶段不是另一轮全剧阅读，也不是为每项资产增加AI“够不够用”的裁判。

1. 既有本集文字生产卡随标准原稿直接交给第三阶段情绪统筹；已采用设计一并提供，没图片也能做文字分镜。
2. 统筹与主创按实际创作需要消费材料；不用的卡不反复进入后续岗位。
3. 缺人物形象、道具功能或场景空间条件时，通过已有局部需求通路定位任务、资产、原文节点与受影响工作包，只补对应材料。
4. 用户明确选定的关键设计仍需采用确认；人工稿、全局采用设计、旧回包及候选历史不被局部补料覆盖。

“没采用设计”“没图片”“没有单独生图提示词”都不自动等于阻塞。有没有足够的创作依据不能只凭引用数量判定；必要的具体缺料仍由第三阶段返回有坐标的需求。

## 本轮实际修改

- 查实普通第一阶段队列默认 `autoAssetPrompts=true`，完成后启动独立全库视觉事实任务。新队列/继续统一为false，并移除完成钩子；旧存档即使保留true也不再由此发起新任务。历史内容不改写。
- 第一阶段页面移除默认付费复选框，改成“第二阶段按需补设计”及入口。全库独立生成不会随资料完成隐式启动。
- 第二阶段保留用户主动的生图、手工编辑、参考图与采用操作；生图外观依据、批量生图提示词标为可选。HTTP生成/事实整理/继续必须有明确选集或旧任务中可恢复的选集，不允许缺范围回退全剧。
- 新增“查看本集文字生产卡”。使用第三阶段同一个 `readProductionEpisodeHandoff`，显示原文事实/角色说法、实际出场/仅素材派生、采用设计、开放设计边界和缺图情况。它是只读显示，不再生成摘要，不确认方向、不派模型。
- 改集立即隐藏前一集卡，取消在途旧读取；读取冲突只报错，不自动重试为付费生成。
- 实稿发现人物名称含造型后缀，原文事实只写身份名称，导致卡内依据未关联。沿用已有源文读取器对 `｜/|` 前身份的匹配规则，补充证据关联；变体沿用基础身份。一字姓名仅匹配明确subject，不扩大到任意字串。没有AI猜别名、编造事实或改原稿。

只读预览协议 `ASSET_PREPARATION_REVIEW_V1` 仅用于页面，不加入模型请求。生产卡仍为 `ASSET_PRODUCTION_CARD_V1`，本轮未改变第三阶段创作岗位、模型、规则或预算机制。
