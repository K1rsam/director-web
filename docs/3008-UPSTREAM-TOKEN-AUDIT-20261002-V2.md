## 修改目的与过程

`foundation-facts`新增历史候选及拒收数量，而原`production-context-v2`只认识旧根字段，导致整个事实包走完整保留的回退。先新增失败回归，复现空历史字段也使机械索引无法去重；再以最小版本化兼容修复转绿。

- 新任务捕获`modelProjectionVersion=production-context-v3`。旧V2、retrieval-facts-v1及无标记快照保持旧处理，不迁移、改写或重跑已付任务。
- V3严格识别历史候选的事实字段、来源、主张、适用性、检索方式及锚点数组，以及非负拒收计数。字段名相同但内部数据未知/异常时仍完整回退。
- 历史候选原样保留，不截断历史原句，不合并解除/反证，不只取最新状态。有历史候选时保留事实编号；被检索锚点引用的机械索引也不能删除。
- 仅本次已发送的、坐标匹配的完整标准原句才能证明机械索引重复。局部请求未发送的源句对应索引、外部文本、明确有效期或额外语义字段仍保留。
- 背景statement只在本次contextRef/contextRefs逐字承载它时省略。对白、表演提示、声道、源事实、资产、情绪契约、方向/设计、承接材料和输出要求不缩减。
- 原件、标准包、canonical输入、历史快照与数据库不变；修改限模型发送视图。未知版本仍明确拒收，不静默选择新规则。
