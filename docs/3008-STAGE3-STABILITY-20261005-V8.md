## 这次解决什么

真实外审指出：最近底稿局部进步、局部损失，不能整份替换。两次此前精修正文全保留，不能拿来证明精修已改善或改坏了作品。本轮分别处理生成端的保全执行和候选采用端的整份替换风险，不增收费裁判或自动循环。

### 生成端：保护作用，不锁画法

情绪统筹、完整主创、统一整编各补一个短段，继续使用既有 `emotionContract.change/landing/retain`，在交稿或取舍前沿完整关联镜核对起势、触发、必要接力与可见结果。`preservedFunction` 只是理由，不是正文已兑现的证据。

- 原文要求突发打断：声音接管尚未完成的动作、气息或注意，不能先演完泄气再换同样表情。
- 关系夺回和权威露底：前后主动权或信息确有差异，不能用通用大脸、回弹代替。
- 整句反击声轨：换画面可以交给被击中者，不逐镜均摊变慢。有效慢说、停顿和关系落定仍保留。
- 有源依据的拦截、接触、松开、接受及呼吸恢复：保住各自作用，只删结果已读清后的重复确认。
- 幻想退出：作用已完成时可交给下一刺激；必要退形、强峰、现实克制与内心主动权不能因此缩水。

不改原话、源因果、已选幻想许可、光影和摄影规则，不增加统一语速、镜长或幻想模板。整数单元末端、容量上限与自然短尾不变。

本轮三段连断行净增 **692 UTF-16 字符 / 1,864 UTF-8 字节**，不是实测 Token 或费用。三岗调用次数和生产输出字段没有增加；合成材料及说明不进入生产提示词。细节见[受限行为对照](3008-STAGE3-GENERATION-BEHAVIOR-20261005.md)。

新任务冻结 `expressive-cadence-v4`；节奏仍为 `screen-rhythm-v5`，精修仍为 `director-refinement-v2`。旧任务使用已冻结文件，不自动升级或重跑。v1–v3 的已知输入投影保持兼容。

### 精修端：按完整修改组采用

候选保留完整原始回包与正文；用户选中组后，程序从冻结基稿拼出实际采用稿，免费校验和保存，不重新调用 AI。

1. 原子替换、多单元幻想的旧新归属、跨单元的同一句发声、已归一化成一个单元的改动，以及同一问题组的关联改动必须一起采用。
2. 默认不选任何组。未选单元和幻想记录必须与基稿精确一致，归一化不得暗中改写或扩大范围。
3. 关联状态、来源、范围、预算/暂停门和既有跨集限制仍核验。若同一句连接到未改单元，只有正文、演法和相对声窗与基稿等价才允许局部采用；否则只预览且不自动扩大范围。无法可靠局部投影的整包承接或资料变化同样只供预览。
4. 原候选不可变，采用结果另存 `refinement-group-selection-v1`。比较、公共阅读和审阅导出使用实际采用稿，不拿未采用的完整候选当成最终稿。
5. 原完整候选的处理说明仍保留，并明确它不等于全部采用。历史候选缺少可靠分组证据时不凭展示文本发明可选组。

接口沿用 `accept_refinement`，新增可选 `groupIds`；显式空、重复或未知组拒绝且不改变基稿。旧版明确整份采用调用保持兼容，不代表页面默认自动全选。

局部接缝检查是保守的场景/出入状态与结构检查，不是表演收益或完整语义证明；未验证的真实声画、跨集成片和创作品质仍须审看。
