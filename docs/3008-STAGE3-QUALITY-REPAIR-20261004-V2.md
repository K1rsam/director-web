# 第三阶段质量保全与自然短尾修复 V2

本记录追加于《节奏与回接修订 V1》，不替代历史结论。用户批准先修连续发声、有效观看、人物情绪作用、解析及必要生产信息，再对连续内容切点做小范围修订。本轮不实施剪辑重叠，不新增默认付费裁判或全剧复读，不重跑已付稿，不提交或推送。

## 已确认的修改边界

- 保住现版有效的2–5秒切镜、完整对白、强表演、近脸、摄影光影声音、长幻想、独立爽点、真实危险及完整救援；不以镜数、字数或时长达标替代演出质量。
- 原文事实、声道、知情、人物主动关系和源动作受保护。换画法可以，不能把“从被安排的位置主动抽身”简化成仅分开两个通用轮廓。
- 同一原句先排连续发声，再给观看切点；切镜不重新摊长少量文字。整编延长自然声窗必须有实际发声或观看冲突依据，不以平读时长或“偏密”笼统判断。
- 幻想首、中、末要有观看作用发展，不把抬臂、屈膝、挺胸轮换当成进步，不给每段硬加新策略。人物速度与相机速度各自成立。
- 连续内容优先靠近容量的合法切点，不默认均分。已有30秒、30秒加7秒自然收尾，就保留；不能为了尾段好看返修前两段或加戏填长。执行批次末尾不是源内容末尾。
- 单元总时长以整数秒交付，镜内仍可用小数；通过成立的切点和有用的动作相位排定，不把显示四舍五入、催读或空等当作完成。

## 实施顺序

1. 版本化修正有独立身份证据的贴写说者动作及明确行中表演；保留原文与映射，旧协议、包身份和任务快照不漂移。
2. 在现有三岗中加强连续声轨、具体情绪作用、重要动作速度及场外同期状态；只传当前范围的紧凑数值/坐标，不复制源话。
3. 让可确定的幻想占时由结构化实际镜内范围计算，避免模型手算合计误差触发大返修；不盲目截断真实事件。
4. 对重要主观/未来视觉主体提供明确清单，和现实出场身份分开；不误宣称未来能力已经发生。
5. 最后补近容量切点、整数秒终点与自然短尾提示；程序只在证据充分时归一，不替模型盲改声窗或演出。
6. 免费回归与历史只读回放，记录实际请求中新增材料和调用变化；真实同稿、配音与视频质量由后续新任务测试，不把合成通过当作质量验收。

## 验证记录

开工前现有第三阶段内核/运行时回归退出0。以下各项在实现后追加实际结果及未测边界。

### 本轮落地结果

1. **接收与旧任务兼容**：新任务采用 `inline-performance-v2`，只在独立人物身份证据和受限动作词成立时分离“苏远抬头os”；明确的行中“恍然大悟的样子”转为表演提示，原件、精确坐标、引号中内容及未知括号保留。确实经过人工裁定的 speaker/channel 用源绑定旁证保护，不能被自动修正覆盖。旧 V1–V4 包及冻结 v1/disabled 的事实、跨集初读/扩读/保留和请求身份按旧规则重读，不因新语法误触发 `SOURCE_STALE`。
2. **连续发声与情绪作用**：统筹、主创、整编共用连续声轨规则；同一句跨镜不重复摊长，整编不能只凭“偏密”否定自然发声。紧凑审计仅传数值及坐标，不复制台词。人物主动抽身、公开反击及真实威胁/救援不被通用轮廓代替；幻想各部分须有观看作用的发展，不强制套三拍。
3. **幻想计时**：新任务冻结 `fantasy-spans-v1`。以实际镜号与镜内范围派生 screenSeconds；一个连续镜可以有多段不重叠幻想，中间现实段不计入。真实超时仍保留原有检查，不通过截断或钳制掩盖；旧数值回包按冻结模式兼容。本轮不是取消正常整集整编，而是避免纯手算误差追加付费局部返修。
4. **重要视觉主体**：新任务冻结 `visual-subjects-v1`，把主观/Q版与未来图示主体和现实出场分开，合并及 Markdown 导出保留；不把未来能力变成现实已发生，不自动扩大素材库或生成图片。
5. **小范围切点修订**：`screen-rhythm-v2` 的近容量、整数终点、分片声速与连续范围坐标进入现有请求。优先成立的情绪/动作/声画切点；合法的 30/30/7 自然尾段直接保留，不返修前两段或填戏。镜内小数允许，整数终点由有用相位安排，程序不自动四舍五入改稿。批次末项不等同源末尾；没有证明结束时不假称片尾豁免。此次不做前后单元重复搬运、自动均分或新增时长暂停门。
