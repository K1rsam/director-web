# 历史记录状态与岗位耗时

2026-09-14。

- 运行表按真实状态显示执行成功、失败、停止、运行中。批准状态与工作稿是否就绪仍由工作流独立判断。真正版本不匹配只标历史版本，不宣称必须重跑。
- 同一岗位汇总最近一条运行所属 deliveryTaskId 的所有记录；按 runId 去重，不混入旧任务。无任务标识的旧记录仅显示该记录，避免猜测分组。
- 耗时优先使用已存 durationMs，其次取开始/结束时间，再用完整调用日志时间范围恢复。运行中、非法或不完整时间保持未知。多批相加表示运行时间总和，不是墙钟耗时。
- 用量与耗时使用同一批次集合；复用、未知、部分用量保留原统计语义。新的 P1 成功记录补写 durationMs，历史记录只读计算，不修改数据库或触发模型。

主控通过：状态正反例、时长回退及任务分组测试、实际用量组件 SSR 与多批整合、P1 接收回归及类型检查。现场只读核对导航岗位显示1分22秒、2次请求；此结果仅验证读数，不代表任务完成。

旧 verify-foundation-ui 的状态断言已按新语义更新。该脚本另有两项关于第二阶段入口的既有断言失败，本轮未改入口行为，未宣称此旧脚本全通过。
