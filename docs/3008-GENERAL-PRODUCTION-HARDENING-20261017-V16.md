# 3008 通用连续制作加固 V16

2026-10-17。按“恢复 → 承接 → 自动交付对账 → 重复读取与上下文”的优先级实现。本次没有重跑成稿、生产模型测试、扩大预算、提交或推送；不是仅给某部剧添加特例。

## 已实现

| 能力 | 行为与安全边界 |
| --- | --- |
| 保存正文免费恢复 | 原授权队列先检查 `recoverSaved`。要求原 request 指纹、当前 epoch/来源、原生 FINAL/RESPONDED、完整正文、本机进程及进程组退出证明；不满足就保留现场。恢复正常整编后可免费 assemble，不经 start，不补发，不自动接受未知费用。|
| 原授权证据等待 | 新四路配置冻结 `evidence-watch-v1`。仅质量/承接证据等待保留原授权及执行者；不伪造质量通过。证据补齐后接原任务，来源、预算、UNKNOWN、硬冲突和无进展故障仍保持停止门。旧配置及停工项目不自动启用。|
| 通用有源复核入口 | 制作页可下载完整双源、当前采用回执、实际尾首稿、上下文和 native 文件哈希；登记单次坐标化复核，仍使用已有 `reviewBoundary` / `resolveSource`。重要源文取舍另需独立明确批准。按本对剧集的选版绑定，不因无关路补位而反复失效；真正双源/稿件/回执漂移失效。|
| 自动文字交付 | 新生产流程默认本地导出；历史流程不回填、不自动导出。必须全部当前采用稿、真实来源/承接及首集实际质量核对通过，无在途/必要返修。直接导出 `assembly.text`，逐集及合订保留原字、镜号和小数时长。|
| 原生费用对账 | 逐集/逐 attempt/按岗位汇总原生 FINAL 用量及执行时长，另列共享账本；request/receipt/raw/event-final 哈希入账。cache 已含输入，reasoning 已含输出；UNKNOWN/非 FINAL/缺证据不造最终用量或模型时间，NOT_SENT 只零派发，不补造 0 回执。观察墙钟含暂停和准备，不相减当纯推理或睡眠。|
| 不覆盖与恢复 | 内容身份目录、`wx` 暂存、逐文件回读、提交前复核、原子发布。中断可续存相同暂存；既有正式目录缺失/变动、符号链接或额外文件都保留并拒绝覆盖。下载重新核来源、选版及字节，不把旧导出冒充当前稿。|
| 启动保护 | 启动只对当前工作流明确选中的未收口目标做免费核对；已接受成稿、旧项目及未选的弃稿不因升级被全量刷新。新增免费写入口也纳入优雅关闭等待。|

代码没有项目名称、固定 130 集、单集特定人物/道具或特例放行。正常场景不需要逐集点按钮；真正语义取舍仍由有源审读决定，不能把关键词、等值引用、机械检查或结构 PASS 当成文字/视听验收。

## 读取与上下文

- 资产范围规划复用本次检查已有的 workspace、源输入和生产范围，原算法及材料门不变；普通独立调用仍重新读取。
- 相同检查仅合并进行中的读取，各调用者持有独立快照；不保留完成缓存，不缓存权限或来源判断。
- 空闲 pump 每轮完整检查由两次减为一次；下一轮及实际派发仍重新检查。没有延长业务超时。
- 新任务冻结 `production-shared-v5`：只给逐字相同的历史证明/场头元数据使用既有 `$same` 等值引用。所有事实、原句、角色主张、坐标、有效期、检索锚点及反证仍在；未知结构保守回退。旧 v2/v3/v4 冻结请求不改写。
- 完整请求与编号投影后独立展开，与 v4 逐字段相等、schema 相等；合成样例实发字符减少。未新增付费实验，不据字符承诺 Token 或金额节省。必要整编、完整来源及创作 Skill 没有删减。

## 使用与产物

制作页增加“承接复核与文字导出”区；同源认证 API 增加 `boundary-evidence`、`boundary-review`、`configure-delivery`、`export-delivery`。来源/身份/目录由服务端持有，下载只接受清单内路径。普通复核不能携带制作解释的批准权限。

默认交付位置：`<生产工作流目录>/deliveries/<workflowId>/<内容身份>/`，包含 `episodes/`、`complete.md`、`manifest.json`、`usage.json`、`report.md`。首集质量审查不能仅凭程序通过自动补签。逐请求问题码保留，不把正常分包或正常 delta 整编误算为付费返修。
