# 3008 按集证据供给 V1｜2026-10-11

本记录追加到既有第三阶段迭代记录，不替代旧结论。范围是资料供给与消费接口，不是重新修改创作方法。分支 `handoff/3008-v2026.10.03.2`，核对基线 `2511c56`；保留此前未提交修改、本机配置、已有任务及用户数据库。

## 为什么不是再提高用量上限

《乌龟》第79集所检查的 Q1 请求，本集工作原文只有794个UTF-16字符，却携带2133条历史候选。主要原因是同名人物的历次对白和普通动作被持续纳入候选，并随邻句扩大供给。不能把这个读取范围当作本集必需背景。

这次保存的 Q1 失败回执明确是 `NOT_SENT`、`providerCallCount=0`，不等于此前整个项目没有费用。没有重新派单，也没有把未知用量填成零。

## 新的供给逻辑

1. 本集标准原稿完整提供，不按长度裁掉对白或动作。
2. 继续提供已确认的精简全剧方向，以及本集适用的文字生产卡；未确认方向不虚构默认定位。
3. 前集承接仍沿既有原文底稿/实际采用尾态机制，不用新的历史补读替代集内 `acceptedContinuity`。
4. 更早历史先给相关状态、身份、关系、知情及解除/反证候选和必要邻句。姓名匹配不再等于全部旧对白都必须重读。
5. 缺具体旧事件时，程序免费取原文，送到有依赖的工作包。省略意味着未默认读取，不意味着事件不存在。

历史信号识别是保守的候选召回，不是语义裁判：不把台词中的“必须、不能”变成世界规则，不把UNKNOWN状态认定永久持续，也不把闪回、幻想或旧造型自动套入当前集。没有另增全剧摘要岗位或付费裁判。

## 程序补读接口

新任务冻结 `episodeEvidenceVersion: episode-evidence-v1`。`historicalSourceDirectory` 仅提供 `[实际集号, 标题, UTF16原文长度]`，不是剧情复述或全剧正文。

第三阶段原有 `productionFeedback.needs` 可提出：

```json
{
  "stage": 1,
  "target": "HISTORY_SOURCE:2:120:260",
  "purpose": "核对本次钥匙交接对象及是否已经接住",
  "packageIds": ["p1"],
  "sourceRefs": ["本次请求已有的源行坐标"],
  "blocking": true
}
```

- `HISTORY_SOURCE:2`：需要时读取第2集完整原文。
- `HISTORY_SOURCE:2:120:260`：UTF16半开范围；程序扩至完整物理源行，不从台词中间截断。长对白的分行仍按原文保留，需要全段时应请求覆盖整段的范围或整集。
- 只读取当前项目中本集之前的实际集号；路径、未来集、缺失集、非法/越界范围被拒绝，错误定位到need字段。
- 返回 `SOURCE_EVIDENCE` 材料，ID为 `history:<target>`，正文协议 `HISTORICAL_SOURCE_V1`；保留原文、范围、版本和 `UNVERIFIED_HISTORY` 权限提示，不生成二次摘要。
- 用到时在回执登记实际材料ID。只有后续采用的消费回执真正读取同版本并不再报告该缺口，才标记resolved；材料存在不等于模型已使用。

当前实现按完整源行补取，不替模型自动推断某段对白的语义结尾。补读原文本身不调用AI；后续必要创作调用仍使用既有预算。

## 防重复与局部失效

- 同一集的重复请求在一次装配中只读一次；同一target输出稳定，不反复追加材料。
- 非统筹消费者按工作包需求取历史原文；统筹读过某资料不等于所有主创都要携带它。
- 版本按实际给出的源范围、文本和权限计算；范围外无关追加不触发已消费材料返修，范围内改动仍严格识别。
- 单纯补料不重跑情绪统筹，不篡改已派单的输入快照；未消费、无关材料变化不触发局部稿件失效。
- 新版模型读包只在来源坐标和文本均精确匹配、引用正文确实已发送时省略历史候选中的重复statement；候选ID、来源、角色主张、有效期和检索关系保留。未知形状/不能证明时完整回退。
- 已给原文但再次报告同一blocking缺口时，不自动无限付费重试；其他无关包可继续，受影响整编停止并保留现稿。这是异常保护，不是“保证任何模型都能一遍过”。

## 旧任务与新任务隔离

未保存新证据版本的任务继续旧供给方式。表演语法 `inline-performance-v2` 与按集历史供给是两个独立版本，不能因表演语法相同而混用新旧准备结果。读取、启动、导出及前集采用结果核对均按任务绑定的版本装配；未知版本拒绝执行但保留旧记录。

本轮没有修改任何创作SKILL正文：幻想、爽感、表演、镜内变化、声音/气口、有效慢说、30秒单元及短尾质量约束不改。资料筛选是否影响真实作品，仍需新稿外审/成片验证，不能由工程测试代替。
