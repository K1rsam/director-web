# 岗位交接：检索未关联不再自动成为生产阻断

## 本次根因

P1、F2、Q1 均成功返回，但最终交接把事实检索器的 unlinkedBackground 一律升级为全局 MAJOR 问题。这个字段只表示词面检索没有关联到角色或全局规则，不表示原文丢失，也不表示已经发现影响制作的矛盾。相同错误在分集读取端再次执行，造成所有集被无依据阻断。

过去的验收甚至把匿名背景必须阻断写成预期。这是岗位交接契约和测试策略的缺陷，不是用户剧本问题。

## 通用修正

- 原文缺口、合法性错误、岗位提出的有据制作问题及用户选择继续走既有范围和接收机制。
- 检索未关联的背景继续保留原文、坐标和候选身份，不删除、不擅自变为全局事实，也不单凭计数制造用户待办。
- 总工作台与分集读取使用一致的边界。已有派生实体交互诊断均按当前原文复验，真实物理冲突仍保护。
- 有明确第1集范围的岗位问题仍影响第1集，不泄漏到第2集。

## 验收

正式导入写入器→已保存P1批次→目录和编辑接收→总态及分集交接的隔离测试通过。覆盖未关联背景原样保留、历史诊断复验、明确问题按集隔离，以及真实来源缺口不得假就绪。既有离线最终门禁保留真实物理冲突和缺失来源覆盖反例。

本轮没有改业务测试项目、增加重试额度、调用模型或替样本收尾。
