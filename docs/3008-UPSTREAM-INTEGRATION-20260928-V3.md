# 第一、第二阶段整合落地 V3

日期：2026-09-28。延续 V1/V2，不替换旧测试、失败证据或第三阶段变更记录。范围是本地3008；没有同步GitHub，没有重做现有付费稿。

## 这轮解决什么

第一阶段不再只是导入后直接跑长文本：保留原句，程序生成标准节点；无法可靠分型的内容显示源行，通过局部确认改变类型/说者/声道，不重写整稿。全剧创作方向独立定稿后，第二、第三阶段共用一份短卡。

第二阶段明确区分原文事实、设计补足、已采用设计和参考文件。提示词生成成功不等于用户已经采用。交接只提供本集相关的已采用简述与参考说明，不广播全部长提示词库，也不伪装读取了图片像素。

## 新稿测试顺序

1. 新建项目并导入小稿，先看“原件与导入记录”。确认集号、场次、作者资料归属正确；不会为省Token删除原件。
2. 全剧工作台 → **标准稿核对与全剧方向**。先处理标准稿中的必要歧义。程序支持明确的同行多说者，保留引号内冒号、原声道与物理行坐标；不明确的头格式仍要求核对，不能靠改成“备注”隐藏对白。
3. 有歧义才使用局部判断建议；普通规范稿无需额外调用。人工选择无模型费用。使用项目CLI/API或Jev前都有明确操作；Jev另需同意把所选原句送第三方。建议不自动采用。
4. 回全剧页整理资产资料。人工改变某集解析后，只有相关集的整理覆盖失效；原文和历史稿仍保留。无需为无关集重买整稿。
5. 定稿全剧方向：主调、副调、背景/机制/主线标签、观众回报、表达原则、避偏和单集弹性。可手写，或显式生成完整来源范围候选；生成前显示预计批次/调用数。候选仍需核对、保存、确认，不能拿“看过一段”冒充全剧定稿。
6. 进入**第二阶段 · 资产形象设计**，核对原文视觉事实，编写/生成提示词。方向只约束气质，不凭空补外貌或剧情事实。已确认方向变化会要求核对旧设计；可保留原提示词并重新确认，不强制调用模型。
7. 对要使用的设计填写600字以内的必要简述，选择实际参考文件，明确采用。没有图片可以仅采用文字。过期设计、未采用设计不作为新任务材料；撤销和恢复都留历史。
8. 查看**交接资料预览**，按集核对标准原文、全剧方向、已采用简述、事实/前情与参考可用状态；下载与页面使用同一读取路径。预览后资料变化，旧下载链接提示重新核对。
9. 再新建第三阶段任务。历史任务仍使用原协议/原材料，不静默替换。真实新稿的艺术效果、人物一致性与Token消耗由此次测试记录评估，不能用工程回归代替。

## 可以重点找的问题

- 集号、说者、VO/OS/旁白、引号内冒号、连续对白是否忠实；无意义空白只收起显示，不改变原件。
- “导演处理/连续性备注”是否位于辅助区，未变成对白说者或剧情事实。
- 全剧主调是否精简、准确，允许单集有情绪变化，没有将“搞笑”变成每场都必须笑。
- 当前人物/变体是否只接到适用设计；第二集采用不相关资产是否错误影响第一集。
- 页面刷新是否找回已有候选、历史和未知结果，是否误触发重复调用；冲突后本地输入是否保留。
- 实际调用数/已知Token/未知用量分别记录；不能把费用未知当0，也不能把传输字符降幅冒充账单降幅。

## Token与稳定性边界

- 已停用的无消费者场稿、重复机械索引延续V2方案；标准原文由程序切片组装，不由模型重抄。
- 资产提示词新返回只需`key/body/suggestions`；旧`facts`字段兼容读取，当前事实文本由程序填入，不要求模型再抄一遍。
- 同一视觉证据的重复引用可用同包`evidenceId`去重；仅当确实更短时启用。原有证据、来源坐标及必要事实不删除。
- 全剧方向只投递已确认短brief，程序上限600 Unicode字符；已采用设计只投递本集相关简述。历史、完整提示词和原件留在存储/人工检查端。
- 局部判断按原文版本、行范围、核对修订、服务和问题版本保留尝试记录。同范围已返回建议直接找回；运行中不重复发起；未知/异常重试需要显式风险确认。没有自动重试或静默Jev→CLI回退。

### 新增材料的真实传输成本

同一合成标准包，计入实际可发送的prompt、instructions及schema：plan 14,883→16,248、author 18,187→19,552、finish 20,962→22,327、delta 21,493→22,858，均净增1,365个UTF-16单位，不是省Token的实测。

其中新方向/设计投影JSON为234单位，新增可引用原句15单位；其余为来源、安全规则、稳定引用和协议开销，并抵扣旧追踪字段。本集/前场重复新增行是0。必要背景暂保留事实表与contextRows双表示，因为不同岗位收到的上下文切片不同，不能只剩一个无内容的引用。这个增量用于新能力，不包装为全链降费结论。第一阶段此前局部F2降幅仍只属于V2报告的那一次实测。

## 当前限制

- 图片生成API仍未接入。本轮支持真实上传参考与人工采用，不宣称完成自动生图或图像验收。
- Jev接线/权限/缓存/未知恢复已做离线检查，但剧本类型判断准确率尚未用真实新稿校准；概率不是批准、事实或删除依据。
- 辅助背景/历史片段作为上下文提供；没有可对照的正文证据时不能自己证明第三阶段`entryFacts`。整段未来梗概仍需遵守揭示时点，未完成全剧语义正确性验收。
- 不支持的混合语法会定位阻断，不承诺任意编剧格式自动猜对。
- 本轮真实模型调用为0；工程通过不等于艺术效果成熟。旧综合套件的已知失败继续单列，不能声称全仓所有历史测试均通过。

这里的0指应用的真实生成/判断调用，不包含本会话开发助手自身的Token，也不是声称开发费用为0。
