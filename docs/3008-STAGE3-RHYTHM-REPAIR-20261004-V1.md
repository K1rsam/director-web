## 本轮修改与保留边界

1. **恢复三种节奏共同规划。** 常规镜以2–5秒为主，普通独立短镜大于1.5秒；超过6秒优先审查拆分，超过5秒的特殊连续镜说明切开会损失的实际收益。中文自然发声按5–6有效字/秒起排，情绪可在4–7浮动，不能普遍以下沿慢读。30秒约8–12个有效镜是设计参考，不是凑数配额。长对白跨镜连续发声，必要气口保留，不能用加速朗读替代剪辑，也不能只缩 `duration` 数字。
2. **以观看变化承载演绎。** 依据原有动作、关系、作用点和听者的变化切镜，摄影与表演共同推进。不能只换机位名称，也不能每个动词各占一镜。已有急起急收、反作用、尺度差、接触重音、近脸峰值、光影及声音方法继续有效；没有搬入“一秒必须八个动作”等计数指标或源外能力。
3. **幻想形式服务具体情绪。** 保留全量、推荐、关闭及用户取消边界。已选机会不以省时、省字或现实感为由降为小图标；长幻想可以跨镜持续，不必频繁退出。关系反转、未来可能、内心判断及实际释放分别选表现机制，避免所有机会套“大头、屈膝、举手、怼脸、回弹”；源支持的同构图反用仍可形成强打脸回报，不自动去重。
4. **接对现实时间与空间。** 用既有主观域、入口出口及单元状态记录最小依据：纯脑内展示可放大一个瞬间；现场对白中的Q化及伴随行走的OS通常仍推进现实。离场者不能无故又留在原门边，真实威压、救援与未完动作不能被主观展开自动暂停；未来兽形不能冒充当前采用形态。紧邻交锋、保护者接近及真正可达距离由既有空间方法处理，不以远机位假装人物已远离。
5. **匿名人物保持一致。** 本集匿名说者随源位置、已供卡片和最小必要设计稳定复用，不因切镜换人、换外观；未知性别不提升为原文事实，未来造型不提前套入当前人物。不为此再生产全剧目录。
6. **局部整编，不加新审稿岗位。** 整编检查上述实际风险，联修切点、声窗、原话分段和幻想引用。正确单元沿用，实际变化及保留收益写进现有 `revisionNotes`；不用新的长自检报告、付费裁判、自动暂停或整套资料重读。

## 程序怎样把检查送进生产请求

新增 `core/rhythm-brief.mjs`，在既有 `capacityBrief` 内提供镜长基准以及当前稿的机械定位：镜头数、总时长、长短镜坐标、稀疏单元、完整原句跨镜合计的标注发声密度及未能测量的行。只送数值与坐标，不再复制原话、场稿或整剧资料。

新任务通过 `captureRules()` 冻结 `rhythmContractVersion=screen-rhythm-v1`，规划、主创、完整整编及差量整编的实际模型输入均可消费。它不是新的输出字段或 PASS 判据，不改变现有回包 schema，也不新增调用。缺失、不完整、畸形声窗保持未知；兽吼等非词语声事件不套字速。普通小短句不因需要气口自动判为慢读。

旧冻结任务没有这一版本标记，继续使用原请求形状和冻结文本。两组历史投影的黄金请求 hash 未更新；测试夹具只明确移除当时尚不存在的新标记。未知节奏版本拒绝，不给历史任务静默换规则。本轮没有改两份已付稿，其前后 SHA-256 分别保持 `5da4fefd5438965a7398574e0bf1e2879fadddd16227fad77fae857f7fa2c018` 与 `b2d0f53f7e0dc39df9b2f8d30c9b016e63b10e03e988a7aba1bc52bdd2249a56`。
