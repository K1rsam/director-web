## 2. 研究结论与证据等级

最值得保留的不是一套固定分镜格式，而是：按用途解释参考素材；把人物动机和情绪落到可见、可听的变化；控制信息揭示与连续性；按交付目标验收；根据具体失败停止无效重试。

本稿区分四种性质：

- **案例指令／能力宣称**：S 的提示词说明“想让模型做什么”，不说明“实际稳定做到了什么”。标题的官方归属也只是转载者表述（S:5–9）。
- **作者实操自述**：优先关注带情境、失败、取舍与残余问题的叙述，例如客户用途误判、开瓶器穿模及优化后仍有瑕疵（T:29、76、132–150）；仍非本研究复现实验。
- **教学启发或作者偏好**：景别与心理效果、各模型星级、脚本／视频“6:4”等可供思考，不能升格为通用规律（M:59–80、166–191；T:114）。
- **本稿推论／用户约束**：锁定剧本与可改编分开、禁止形式配额、避免无效多轮，是本次取舍边界；后文迁移建议不是三份材料已经实现的功能，也不是已批准的新系统设计。

M 与 T 都与 A稳／Binghuo 品牌有关；S 是署名 A先生的案例汇编。三篇不能当作三组相互独立的模型评测。商业推广不使实操观察自动失效，但销量、效率、成功率与能力保证需要另证。

## 3. 参考素材：语义角色比文件类型更重要

S 明确区分“使用对象／参考对象”和“参考／编辑”，要求核对各个 @ 对象，避免图、视频与角色混淆（S:49–63）。其真正可迁移的价值是：**同一素材可只贡献某个属性，不能默认继承它的全部内容。**

| 素材承担的角色 | 文本证据 | 对推理的启示／边界 |
|---|---|---|
| 人物身份、外观 | S:179、256、832、1136 | “只参考形象”不等于复制姿态、背景或剧情。角色身份与当前状态分开。 |
| 场景、空间布局、移动路径 | S:144、201、793、832 | 区分上／左／右场景、拐角、走廊、目的地；一组场景图不自动等于一致的三维空间。 |
| 产品结构、材质、多视角 | S:131；T:132、150、152 | 包的侧面、主体、表面材质来自不同图片；开瓶器还需表达手—工具—瓶盖的接触关系。 |
| 动作、表演、表情变化 | S:179、256、457、1095 | 动作路径与表演强度有独立来源，不应被服装／人脸参考覆盖。 |
| 运镜／视点 | S:222、238、281 | S:281 分别从视频1取动作、视频2取环绕运镜；文件“都是视频”不代表作用相同。 |
| 剪辑节奏、转场、特效结构 | S:92、302、324、426、1015 | 应明确借用哪种节奏或转场；“全部照搬”易把参考剧情或无关造型也带入。 |
| 音色、语气、口音、配音内容 | S:651、732–735、750–754、815 | 声音风格、说什么、由谁说、何时说是不同约束；不能只记一个“音频参考”。 |
| BGM、节拍、音效 | S:519、637、981–1041 | 音乐可决定节奏与情绪，而不决定角色身份；视频也可只提供声音。 |
| 漫画／分镜脚本／阅读顺序 | S:485、503、1069 | 明确逐格顺序、台词保持、参考范围；与自由发散不能混用。 |
| 灵感／情绪意象 | S:519 | “以图为灵感”允许重新组织表达，不代表逐张图都必须变成一镜。 |
| 起止画面或关键状态 | S:55–56、410、815；T:150 | 首帧、最终外观、动作关键帧应分别标明；三者不是天然同义词。 |
| 待编辑的既有视频 | S:898–966 | 它是编辑对象；另需说明保留部分、修改部分及剧情是否允许变化。 |

本稿推论：交接参考时，最少说清“哪个对象、取什么、用于哪一段、哪些内容不继承”。不是让每镜填写全套字段，也不是素材越多越好。素材不足应显式暴露，不由模型猜出侧面结构、人物身份或缺失声音（依据 S:52、832；T:152）。

## 4. 动作、声音、情绪与叙事节拍

### 4.1 动作首先是因果，不是动态词堆积

- S:15 的晾衣动作有先后关系；S:38 的逃跑包含撞摊、爬起、继续逃；S:63 明写跳跃直接接翻滚。可提炼为动作起因、接触／发力、状态变化、结果及下一动作，而不必每个动作都切镜。
- T:104 将拉狗动作安排在产品展示中，同时交代功能和人物自然反应，强调先设计“为什么发生动作”，而不是事后用提示词增加真实感。作者点名第5、13秒，但本研究未观看，不能确认动作、时间点或效果。
- T:132–150 的开瓶器自述更具体：文字难说明特殊结构，先锁好手、瓶盖、工具的位置，再引导关键动作；优化后仍有瓶盖形变问题。这支持“先消除状态歧义”，不支持“加一张图就必然解决物理交互”。
- M:195–207 对静态关键帧的起势／发力／结果拆解有用；但“绝对不能在一个镜头体现全过程”把静态图、连续视频与镜头混为一谈。S:63、793、832 恰好给出连续动作／长镜头的另一种意图表达。两者都不是本次实测结果。

### 4.2 声音参与叙事，不只是后期铺底

S:24 以脚步声触发人物掩饰行为；S:684 以画外“且慢”中断争执并使两人转头；S:732–735 把闹钟、叫醒、躲被、叹气分成连续反应。这些是声音改变人物行动和观众注意的例子。

可区分：台词原文、说话者、轮次、语言／口音、音色、语气、画内或画外、触发动作、环境声、BGM 与剪辑卡点。S:670–719 有双人及多人对话、戏曲、英语与西语等意图；不能据此保证多人归属、口型、发音、语言覆盖或同步精度。

M:312–316 以迟迟不落的烟灰表达沉默时间；S:117–120、1015–1041 则用画外音或节奏推动广告。留白、沉默与音乐卡点是不同选择，不应强制每个节拍加音效或每次切镜都卡音乐重拍。

### 4.3 情绪目标保留，外化方式具体化

M:118–145 建议把心理描写翻译成动作、表情、环境，M:338–343 进一步指出直接写“开心／难过”容易演得过满，主张微表情、生理细节和动作暗示。M:380、400 的更重要原则是：运动为情绪服务，运镜要有速度、时长与目的。

不能因此把抽象情绪从推理中删掉：S:79 描述疲惫→门前调整→面对家人的轻松，S:1095 是沉思→崩溃。外在动作是否合适，恰恰需要情绪意图与变化作为判断依据。M:120 把“绝望”改成跪地捂脸，只是一种表演方案，不是所有人物绝望时都必须下跪。

本稿推论：先明确观众此时需要感到什么、角色在压抑或试图掩饰什么，再选择足够的可见／可听证据。微表情也不是配额；远景、静止、遮挡或不露脸都可能是经授权的表达选择。不要用“每镜多一个特写／运镜／生理细节”替代判断。

### 4.4 节拍、镜头与生成片段分开理解

- 叙事节拍可看作一次有意义的信息、关系或情绪变化；S:79 的回家过程可提炼为疲惫、掩饰、被迎接，划分依据是变化，不是字数或镜头数。此为本稿分析，不是原文命名。
- S:921–926 的零食广告先建立危险预期，再揭示零食并松弛，说明节奏来自预期／反转／反应。S:117–120 的分时广告则主要安排商品信息与使用场景；不能把这套时长直接套到人物戏。
- S:793、832 允许一段连续镜头经过多个空间／关注点；M:265–283 用多镜逐步揭示情绪。一镜可以承载多个节拍，一个节拍也可能需要多个镜头。生成片段还可能包含内部剪辑，并不天然等于“一镜”。
- S 中 8秒、15秒及分段时间码是案例要求，不构成模型上限、统一单元长度或准确落点的证明（S:503、594、732–735、1069）。

取舍：先确定剧本事件、信息揭示和情绪节奏，再确定镜头组织及生成边界；不得从“四宫格／九宫格／每段15秒”反推必须增加多少戏。

## 5. 连续性与剪辑：不能缩减为“不换脸”

M:209–212 要求同场景保持环境、时间、空间与光效，M:218–242 引入人物／场景／道具资产；S:68–69 则罗列人脸、服装、商品、字体、场景与风格一致性。方向有用，但“相同环境后缀”与资产图并非完整的连续性保证。

研究上需要区分以下对象，按具体场景选择，不要求逐镜重复全文：

- 身份与外观：同一人、衣物、道具及产品关键特征；状态可随剧情改变，身份不应漂移（S:69；M:220；T:88）。
- 空间与行动：站位、视线、运动方向、进出画与场景路径；S:201、832 已使用拐角、追随和位置关系。保持场景不能误解成机位、构图也不许变。
- 物理状态：手是否接触、谁持有道具、动作前后是否接得上；T:150 给出明确接触约束。不能只写“保持连贯”。
- 表演与信息：上一段累积的情绪、人物知道什么、何时揭示；S:79、921–926 的变化如果乱序，单帧一致也不能救回叙事。
- 声音：台词归属、说话轮次、语气和触发关系；S:684、707、719。跨片段音色稳定是应验项目，三份文本没有证明可自动长期锁定。

这里的空间、状态与信息检查是本稿综合推论；材料没有给出完整的轴线管理、遮挡几何、长篇角色记忆或跨片段状态实现。

剪辑方面，应区分两层：

1. **生成内部的剪辑／转场意图**：S:92、302、324、426、1015 要求参考运镜、切换节奏、特效与卡点。这些只是待验证指令。
2. **成片剪辑与复查**：M:404–417 明确强调视听整合。作者承认 2025 年《回到2006》有发音、变脸、文字畸变等问题，尝试剪辑补救后仍因瑕疵太多未发布；这是有失败边界的自述，不是“后期能修一切”。

还需警惕原文语义冲突：S:105 同时写“一镜到底”和“镜头切到”；M:319 写从下往上微仰拍，M:322 的解释却说“俯视的机位”。可理解为用词不严谨或不同层次表达，不能直接编译为无冲突的摄影指令，更不能凭文字判断示例成片是否出错。

## 6. 首尾帧、全能参考与视频编辑

核心辨析：**边界状态约束**与**参考属性的分工**是两个维度；不能预设它们互斥，也不能预设某个产品入口一定实现全部组合。

| 语义／工作方式 | 三份文本确实提供了什么 | 不能据此认定什么 |
|---|---|---|
| 首帧／尾帧意图 | S:55–56 提到首尾帧图并举“图1为首帧、参考视频动作”；S:815 明确首帧；S:410 指定最终人物外观。 | “最终像图2”不等于严格尾帧锁定；自然语言首帧声明不等于 API 硬约束或像素级复现。 |
| 全能参考 | T:129 明称 Seedance2.0 全能参考模式，并认为图片权重很高；S:50–63 说明多模态与角色分工。 | 作者感受不是公开数值权重；本地材料未给完整模式矩阵、接口字段、输入上限、优先级或冲突处理。 |
| 单个动作关键帧 | T:150 用首帧锁定手、瓶盖、工具；M:195–207 分解动作关键状态。 | 关键帧是行动设计概念，不是某个固定入口的专有能力；不能因此要求所有片段先画全套分镜图。 |
| 延长／前接／中间插段 | S:57–60 说明新增时长与插段意图；S:553–610 有延长及“向前延长”案例。 | 不能推断所有入口都支持、时长限制仍相同、与原片衔接必然无跳变。 |
| 定向编辑 | S:899 宣称能保留其他内容并定向修改；随后 S:909、921 却展示颠覆剧情的要求。 | “编辑”不天然等于局部修补；不能将新增剧情视为默认许可，也不能保证非目标部分零变化。 |

对后续研究的判断顺序：需要的是严格边界、外观参考、动作示范、声音参考，还是编辑已有片段？先说清保留／可变内容，再由主任务根据官方现行能力选择入口；不要从单一图生视频流程反过来限定全部创作。

## 7. 锁定剧本与可改编：必须独立授权

这是用户明确要求的边界；三篇材料没有完整定义这种权限模型。

| 情形 | 应保留什么 | 可探索的范围 |
|---|---|---|
| 锁定剧本的视听转译 | 已写明的事件、因果、台词与归属、关系、动机、信息揭示和关键动作；不删除未分到镜头的事实。 | 在不改变上述内容的前提下探索机位、表演强度、节奏与可行生成组织；会新增显著含义的动作需另行确认。 |
| 获准改编 | 明确哪些事实仍不可动，以及允许增删、压缩、重排到什么程度。 | 可提出新动作、心理转折或情境，但标注来源之外的改编及其影响；不能悄悄替换原稿。 |

三个文本内的警示例子：

1. **坟前九镜不是忠实转译的证明。** 原段写少年脚步轻快、缅怀父亲、把酒葫芦放坟前并抬头看天（M:261–262）。九镜解析强调沉重、遗志与“悲痛到决意”，末尾增加紧握木剑的心理蜕变；未明确分配放酒葫芦及抬头看天这两个原动作（M:265–283）。这可以是作者的改编解释，不能当作已逐项覆盖原文。
