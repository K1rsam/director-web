## 二、总判断

五篇属于同一 Binghuo 资料体系，不是五份独立效果验证。它们分别偏向视频提示词、排版接口、武打类型化生产、文生图 SOP、多格视觉规划；不能拼接成一套全部强制生效的“导演铁律”。

最值得保留：先理解情绪与关系、原文可追溯、资产身份稳定、动作有结果、镜间状态可承接、视听选择有目的。最应拆开的四种单位是：**戏剧/台词单元、剪辑镜头、生成片段、分镜板画格**。12/15 秒是资料中的生成组织方式，不应反向规定戏剧长度；宫格数量也不应规定剧情节点数量。（A L64–78、L488–510；C L515–532、L711–726；D L236–247、L303–339；E L80、L109、L137–146）

## 三、逐篇机制、反例与适用边界

### A｜15秒专业提示词：可取其承接、表演与声线分层，不能整套照搬

- **有效机制 / 字段：**前后各两条分镜作为上下文；角色别名归一化；区分稳定身份与状态变体，例如“洞口”另一个场景、“受伤的叶辰”仍可归同一角色。镜头要回答拍谁、拍哪个部位、主体动作、跟随动作、信息点、机位运动；声音分成固定 VoiceID、可变的身体/情绪/目标、逐句语气。这里“想压制、套话、安抚、转移话题”比单纯“愤怒70%”更能解释人物行为。（L18–23、L42–60、L102–110、L427–453）
- **真正支持用户偏好的段落：**允许音画分离、重视自然流露；“反应比台词重要时，给听者特写”；深情场景可以慢节奏；台词不改原词而可跨画面。可保留这些原则，但不能同时强制每句话都先拍嘴再拍听者。（L118–129、L143–149、L455–457）
- **配额与规则冲突：**标题15秒，主体却反复固定12秒，声线段又出现10秒；有“三镜一组”，也有4/7镜惯例、3/5/6镜例外及镜数不限。台词≤10字/句、≤4字/秒，与后文≤5字/秒并不统一；禁止表演停顿又要求停顿、呼吸与静默。每组末尾永远1秒转场、效果随机，会把技术分段变成不必要的情绪中断。（L1、L64–78、L453、L486–510、L642）
- **可核查的示例失配：**夫君整句25个汉字被塞进2秒，即12.5字/秒，尚未计换气、动作；文内上限至多5字/秒。毕业聚会输入写“跪下”，输出改成“倒下”，画面写倒地、配音状态却仍写跪地。山路女主镜头标题写“扫过桌面物件”，正文实际拍脸；末尾又新增输入未给出的“山贼抢走夫君”反转。（L689–690、L713–720；L653–658、L673–684；字数计算不含标点）
- **另两类冲突：**信息库外元素“绝不能出现”，格式却允许“自行分析”；先要求焦段等参数，后又禁止这些技术术语。严格“不能新增动作”与心理外化也需要明确授权边界，不能靠示例悄悄突破。（L26–34、L43、L134–140、L497–500、L534–537）
- **吞咽风险与锁定边界：**吞咽/喉结、指颤、眼缩在规则和多种情绪中反复套用，并不自动产生活人感。建议锁角色身份、已批准台词、必要承接状态；不要锁死表情菜单、情绪百分比、镜数或固定转场。微动作须能回答“此刻为什么发生、作用于谁、改变了什么”，允许克制或不动作。（L74、L87、L107、L113、L679、L711、L717）

### B｜分镜排版：是轻量表达格式，不是通用戏剧逻辑

- **有效机制 / 字段：**`参考对象＋主体＋动作链＋镜头光影＋特效`，以及时间段、画面、运镜、台词的显式分工。角色参考有利于身份关联；动作先后顺序有利于描述结果。（L24–27、L34–45）
- **具体例子：**样例从眼尾特写，到过肩中景说“泽泽，奖励我”，再到双人拥抱与拉远，兼顾距离变化和安静的余韵。它并未真正按“每段第一人称解说”或“强制速度线、冲击波、环境碎裂”执行，反而暴露后两项不适合这场亲密戏。（L28–32、L39–45）
- **风险：**禁止单一动作、必须三段动作链，会让简单凝视也被填充；强制高燃特效、第一人称、40字上限会改写题材与叙述视角。样例的0.3秒“参考人物”是模板中的技术性片头安排，不应无条件算作戏剧镜头；样例总长10秒，不能读成本文强制10秒，更不能读成15秒。（L26–32、L41–45）
- **边界 / 启示：**适合作为决策完成后的排版接口。参考身份、字段分隔符可固定；动作数量、视角、特效和台词长度须服从该场戏，不宜在研究阶段锁定。

### C｜分镜提示词最新：溯源和容量检查有价值，硬约束互相挤压

- **有效机制 / 字段：**逐句原文覆盖、对应原文栏、先通读再分叙事单元；判断内容能否“从容演完，不加速、不挤压”。输出包含人物站位、视线、动作、物理反馈、音效与画面承接；攻防的发力、接触、收力及后果，比只有招式名称具体。（L515–532、L563–607、L721–726、L400–406）
- **配额风险：**先说13–15秒可拆合，最终却锁“单镜3秒、总15秒”，形成五镜等分；正文又要求高潮每2秒切镜。模板五段预填开场钩子、发展、两次转折、衔接，检查项却说只有整集第一段有开场钩子。最低描述长度亦有150与180字两个版本。容量原则被秒数、剧情槽位与字数考核反向覆盖。（L310、L525–540、L587、L612、L636、L661、L685、L711、L724、L768）
- **活人感被“一致性”误伤：**所有对手戏面对面持续眼对眼、所有持剑动作始终剑尖朝天、整集眼神/节奏/参数100%相同。这会排除回避、试探、偷看、关系变化，也难与挥剑/刺击动作同时成立。应锁身份与可解释的连续性，而不是锁姿态和情绪反应方式。（L24–28、L248、L331–345、L408–428）
- **视听自相矛盾：**禁止停顿蓄力，后要求击中停顿；禁止静止帧，模板末段却定格；禁止音乐，末尾又留“情绪音乐”；禁止手部特写，同时有拳头/攻击接触点特写。无论戏剧内容，开场0秒即打斗、高潮必须静音0.3/0.5秒、各类参数按倍数增强，都把“戏剧强度”窄化为感官强度。（L220、L240、L262–288、L398–404、L463–471、L693–715、L784）
- **忠实性冲突：**允许台词改写与要求一字不改并存；要求100%保留原文，又自动替换/删除所谓违规内容。“称霸→守护”“死亡→失去战斗力”等会改变人物动机或事件后果，不能自动认定原意不变。（L20、L124–164、L190–200、L515–522）
- **证据与锁稿边界：**文中“2026年4月最新公约”、蓝血可过审、0.88运动幅度、渲染开关等均未附可核验依据，本轮没有验证，不能当官方规则或真实可控接口。要求自检“全部打勾”也不等于通过测试。建议只继承溯源、状态承接与容量复核；平台限制另行验证，不能写进导演层的永久铁律。（L22、L108、L502–512、L729–810、L847）

### D｜标准SOP：最接近情绪先行，但偏文生图，且鼓励过度拆镜

- **有效机制 / 字段：**先写核心情绪弧线、关键视觉节点、角色场景和媒介风格，再确认资产；角色锚点含脸型、服饰、发型，道具只列推动剧情或反复出现者。镜表含镜号/时长/景别/锚点，对话标记是“谁→谁、情绪、节奏”；强调不机械要求谁说话就拍谁。（L236–301、L328–357）
- **具体例子：**A说话→B倾听→B反应→茶杯→B回应，说明说话声与被观看者可以分开；但茶杯只有承载等待、遮掩或关系信息才有理由插入，不能因示例里有它就必加空镜。（L704–719；后半句为本次建议）
- **关键冲突：**镜数按剧情、不设上限、时长自然推断，却要求每句关键描述至少拆3–4镜，并考核拆镜完成率；还倾向对话镜不超过5–7秒、每镜2–3细节、文生图120–180词。镜头覆盖清单可能变成角度凑数；情绪高潮一律慢镜、紧张一律快切也只是类型惯例。（L74–78、L305–326、L337–357、L405–419）
- **台词边界尤其重要：**禁止直接引用台词适用于其图像提示词取向；若把它作为完整音视频分镜，就会与“禁止机械删减关键对白”发生缺口，且对话标记不能替代真实台词、连续声轨和口型时序。应在独立的剧本/声音记录里保留原句，再让画面自由选择说者或听者。（L22–32、L328–357、L396–400、L666–682、L799–803）
- **锁定边界 / 启示：**风格确认、资产确认是合理关口，不等于分镜已锁。身份特征稳定与身体状态变化要分开；每镜承接也不等于每个动作重复演一次。可将“情绪弧线”和“对话对象”前置，镜头知识库后置为可选工具。（L68–84、L250–301、L316–320、L426–499）

### E｜分镜板：适合共同评审，不足以单独证明时间与表演成立

- **有效机制 / 字段：**先提炼角色、地点、冲突、主题，再为各格标编号、标题、画面、参数、剧情说明；底栏整合节奏、参数与备注。先评审分镜板再进入视频阶段，有助于统一可见方案。（L32–50、L81–91、L120–135、L243–265）
- **例子与边界：**“流放军官发现沉睡战争AI、舰队逼近，面临摧毁或结盟的选择”是探索性梗概，允许提出视觉候选；不意味着已授权替用户决定选择结果。资料明确会自动补全，不询问、不提供多个方案，因此不适合直接作用于已锁剧情。（L60–63、L75、L289–295、L320）
- **九格不是普遍定律：**完整版明说可多可少；后续却展开固定九段，简化版直接要求拆成九个连续镜头。默认建立→入场→线索→冲突→打击→升级→高潮→收束，会把静态关系戏推成动作预告。“不要只生成一个场景”也混淆地点与画格，不应据此强迫同场对话换地点。（L109、L137–146、L180–241、L279–286、L303–314）
- **视听与锁定边界：**有镜头参数并没有解决台词、呼吸、反应发生时机或单镜容量；分镜板通过只说明静态规划获认可，不能等同视频表演通过。板面科幻UI是展示皮肤，不应侵入所有题材的场内设计。镜头数和格数宜分离，可分页而不补戏凑格。（L106–118、L178–265；后两项为本次建议）
- **效果仅属作者陈述：**L11称“一张图、一次性、无剪辑、Seedance直出”；L330–334展示另一图→提示词→视频流程。本轮只读这些文字与附件标记，没有看图或视频，无法确认效果、过程或可复现性。

## 五、锁稿适用边界（分析建议，五篇未给完整版本锁稿制度）

资料中明确的是资产/风格确认、原文约束和板面确认，不是“何时锁稿、谁可解锁、变更影响哪些下游”的完整制度。（A L42–60、L427–457；C L515–522；D L250–301；E L81–91）

- **剧情层可锁：**已确认的事实、人物目标与关系转变、关键台词原文及归属。锁的是戏剧意图，不是预先选好的景别。
- **连续性层可锁：**角色身份、场景空间关系、道具归属及当前状态；受伤、换装、起身、转移目光仍可因剧情发生，并须留下状态变化依据。
- **表演与分镜层后锁：**待动作、完整台词、倾听反应与留白确能承载情绪后，再锁镜序、声画关系、必要切点；生成技术切段不得默认改剧情或机械切词。
- **生成与板面层局部锁：**交付某次生成时可固定参数、输入图、编号和格式；容量或可实现性不符应回报受影响部分。不能用“已锁”阻止修正事实错误，也不能因重排九宫格而擅增剧情。

## 六、对“情绪先行 / 活人感 / 视听服务戏剧”的直接启示

建议下一阶段先问“人物此刻想让谁怎样、遭到什么阻力、观众何时感到关系变化”，再决定行动、观看对象与声音，最后安排镜头、估时和平台分段。依据是 D 的情绪先行、A 的身体/情绪/目标分层与听者优先、C 的从容演完原则；这是选择性重组，不是照抄任何一篇。（D L236–247、L305–306；A L127–129、L440–453；C L530–532）
