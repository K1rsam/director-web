## 工程师按问题选读

- **情绪与表演**：ACTING → 漫剧老李的emotion-beat-curve / cinematic-dramaturgy-rules / wenxi-micro-expression；先确定观众体验和人物策略，不能靠固定12点曲线或表情配额代替分析。
- **空间、主体与摄影**：CINEDANCE → spatial-topview-camera / camera-specs-15rules；分清世界位置、画面左右、相机和主动主体负荷，不能把整场名单塞进每镜。
- **全剧前置与资产**：灵墨第4、5、6阶段 → asset-first-pipeline / asset-spatial-ledger；分开清单、外观设计和实际素材；核集合和状态，避免以数量齐全替代源文覆盖。
- **锁稿/允许改稿**：先看灵墨第1至3阶段的权限差异。它们存在实质改写/合规替代，不应直接用于不可改的甲方稿；跳过2/3也不保证5的默认外观设定保真。
- **局部返修**：LIRA的CHANGE/PRESERVE＋我们[已有复盘](../cto-handoff/business-handoff.md)；保护正确区域，复核受影响连接，不重写无关内容。
- **模式与单元**：15/30模式先选，合理时默认尽量接近上限；短单元须具体理由，内部镜头可以快速变化。任何旧文“只作上限”或固定12–15秒条款都不能独立覆盖这一完整偏好。
- **模型适配**：先核真实CLI/API/视频入口、模型、工具和上下文。原文中的参数示例、默认厂商偏好和“零变形”等均非本项目实测结论。
