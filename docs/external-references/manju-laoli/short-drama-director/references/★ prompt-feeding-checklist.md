## 〇、 执行铁律

1. **画幅先行**：写任何提示词前，先锁定画幅（用户指定 16:9 → 全流程横屏；未指定 → 9:16 默认），见 `aspect-ratio-adaptation.md`；
2. **按序过检**：以下 6 步按顺序执行，每步产出对应校验结果，全部通过才允许出稿；
3. **语速卡不入正文**：语速自检卡是内部 QC 附件，默认不写入投喂正文（避免污染提示词），但必须随交付物一并输出；
4. **战斗档二选一**：R3 玄幻 → `xuanhuan-magic-combat.md`；武侠/现代格斗 → `action-previs-15grid.md`；两者不混用。

## 一、 六步必查序列（缺一不可）

### Step 1 · 模板与时长预算
- [ ] 读 `seedance-render-engine.md`（★主模板）
- [ ] 时长预算公式核对：目标组数 = 预估成片秒数 ÷ 12~15s
- [ ] 每组 ≤15s（单镜 3~5s，一组 3~4 镜）；高密度动作段改**微步进切片**（0.5~1.0s/片）
- [ ] 每组自带完整时间轴（从 00:00 开始）、画幅风格、资产短锚点、负面词

### Step 2 · 画幅路由
- [ ] 读 `aspect-ratio-adaptation.md`（★权威）
- [ ] 交付物顶部显式声明 `【画幅】：16:9 横屏 / 9:16 竖屏`
- [ ] 每条提示词/每个 API 载荷回填 `aspect_ratio=锁定值`，零回落
- [ ] 构图按画幅套版：横屏=三分线左右站位/对角线动势/横向位移；竖屏=垂直落差/俯仰对峙/冲镜特写

### Step 3 · 镜头规格
- [ ] 读 `camera-specs-15rules.md`
- [ ] 每镜镜头五要素齐全：`[景别] · [视角+角度] · [运镜] · [跟随目标]`
- [ ] 中景/全景严禁 90° 侧面正拍（必须 30°~60° 斜角）
- [ ] 连续镜头景别阶梯跃迁（极微距特写→超广角中景→宏观全景→鸟瞰/过肩定格），禁相同景别+机位连排
- [ ] 15s 高燃段：开局 0~1.5s 见肉、同运镜 ≤2s、以高潮定格收尾

### Step 4 · 对白三查（有对白必过）
- [ ] 读 `dialogue-speed-check.md`（语速）+ `wenxi-micro-expression.md`（微表情/发酵）
- [ ] 每条台词拆句→计数→套档（标准 3.5~5 字/s / 慢速 <3.5 / 快速 >5）→速算→判定
- [ ] 台词时长 ≤ 该镜预算（超时=🔴 P0，必须重构或拆镜）
- [ ] 单句 >24 字强制拆 2~3 镜（每镜 ≤18 字）
- [ ] 金句/高潮台词后预留 0.3~0.8s 无对白反应镜头（瞳孔骤缩/倒吸凉气/静场）
- [ ] 文戏微表情按六阶段生理递进（触发→初识→压抑→泄露→破防→余韵）

### Step 5 · 战斗档语法（战斗段必过）
- [ ] **R3 玄幻**：读 `xuanhuan-magic-combat.md`（★权威）
  - [ ] 法宝媒介施法（禁拳脚抽象"施法"词）：材质+施法动作+特效出口
  - [ ] 五行属性绑定+双色粒子（属性即视觉语言）
  - [ ] 术法攻防循环：祭防御→破防临界→**防守转攻**（高光必写）→瞬移残影
  - [ ] 能量具象化：光柱/具象生物/巨型化法相/领域道域
  - [ ] 蓄力前奏必写：天地灵气汇聚/能量漩涡成型
  - [ ] 对军清场：战场破坏反馈（沟壑/陨石坑/碎片）
- [ ] **武侠/现代**：读 `action-previs-15grid.md`（11 环动力链/防守三态/R1~R3 强度档）
- [ ] Seedance 2.5 特性：Hit-Stop 0.1s 打击阻尼停顿标注、`[SFX: ...]` 原生音效

### Step 6 · 出稿质检
- [ ] 读 `quality-gate-review.md`
- [ ] P0：时长 ≤15s / 台词未篡改 / 无跳轴 / 画幅一致 / 锚点指向已登记资产
- [ ] P1：受力过程完整（非光污染对波）/ 节奏快慢变化 / 光源物理真实
- [ ] P2：无空镜 / 反形容词 / 声音三层（对白 0dB > SFX -6dB > BGM -14dB）
- [ ] 锚点全部指向《资产图册》已锁定资产图（无图=门禁 3/4 阻断，回补 P2c）
