## 2026-09-02 · 下午二次修正（静止段禁用铁律 + 高密度节奏聚合范例）

> 背景：用户实测两版聚合提示词，反馈“节奏太拖沓”“最后4秒蓄势待发浪费”。诊断出 skill 设计深层病根——**AI 视频没有“静止表演”能力**：写“对峙2秒/蓄势待发/留白/悬停/站立/特写定格”类静止段，模型渲染成角色呆立几秒。这些规则源自真人影视美学移植（眼神戏/微表情/情绪惯性），AI 模型不会表演。

### 🧩 修正（Fixed，2026-09-02 下午）

- **总纲铁律（新增于 `action-previs-15grid.md` 〇节）**：一切情绪与蓄力必须在运动中完成——边打边蓄、上升途中蓄、后撤中蓄；神态挂载在动作瞬间（甩剑转身时冷笑），不单独成段；唯一允许的“定格”是命中瞬间 1~2 帧微停顿（Hit-Stop），其余静止段默认禁用。
- **开局/节奏呼吸感**（`action-previs-15grid.md` 完播率表）：删“微慢镜定格”，改“命中瞬间微停顿”；节奏反差用 Hit-Stop 或瞬间加速，禁用慢镜/升格。
- **大招模板去静止**（`anime-ultimate-vfx-paradigm.md`）：删“特写悬停”；蓄力段标注“必须边动边蓄：旋腕/踏步/上升中凝聚，禁止悬空静止蓄力”；“定格人物全身”改为动作瞬间抓拍。
- **长运镜范例换代**（`action-cinematography-breakdown.md` §四.5）：旧版“缓慢拉远+悬空挑衅+蓄势待发”已废（用户实测拖沓），替换为高密度节奏版——5 节拍（横扫→硬碰→升空→剑阵→万剑齐发轰地），结尾直接放大招，无蓄势定格；机位绑定表“中场留白”行标注禁用。
- **武戏情绪节拍默认禁用**（`combat-rhythm-defense3state.md` §四）：中段意境留白、招牌神态记忆点均标注“2026-09-02 实测二次翻车，默认禁用”，替代写法=运动中换档（滑步后撤中蓄力/环境介质撑节奏），神态挂载动作上。
- **美学构图去静止**（`cinematic-dramaturgy-rules.md` §五）：中心对称蓄力镜改“边动边蓄”；剪影只用于动作瞬间（滞空/挥动/位移中），禁静止特写；收尾改命中 Hit-Stop 抓剪影，禁静止收尾。
- **运镜词表去慢镜**（`camera-specs-15rules.md`）：删“慢动作跟镜/定格定镜”，改“命中瞬间定格（Hit-Stop 微停顿 1~2 帧）”，标注慢动作/升格默认禁用。
- **微步进示例对齐**（`seedance-render-engine.md` §二·五）：示例定格改“命中瞬间 1~2 帧微停顿”，补注“禁角色静止站立/悬停蓄力/对峙”。

### 📌 沉淀

- **投喂版定稿**：女帝战巨兽 15s 高密度版（单一连续运镜 + 5 节拍 + 万剑齐发收尾 + 零 SFX 标记，适配 Seedance 2.0），已入 `action-cinematography-breakdown.md` §四.5 标准范例。
- **开场景别锁定（2026-09-02 实测反馈）**：用户测试后反馈“开场人物特别小”——长运镜第一帧从大远景/军阵全景起手会导致主体过小。已修正：第一帧必须锁定主角**中近景**（人物占画面 ≥1/3），军阵只作背景，镜头随动作前冲再拉开；规则已写入 `action-cinematography-breakdown.md` §四.2。**用户已实测通过 ✅**。
- **速度感三要素（2026-09-02）**：极速推进感不由“远景起手”提供，而是①背景视差（主体中近景锁定，背景高速倒卷）②前景遮挡（碎石/残影掠过镜头）③同向加速运镜。中近景+背景高速倒卷才是标准解法。
- **场景图分型（2026-09-02 用户决策）**：**文戏用机位调度图（CAM1~4），战斗用角色站位图（@锚点站位+轴线）**。`asset-spatial-ledger.md` §四 已升级为双模板：文戏机位调度版（保留原模板）+ 战斗角色站位版（用户实战版固化，补齐主色调+氛围字段）。战斗=武打/玄幻法术/枪战/战争等一切战斗类型（用户修正术语：不单是武打，应叫战斗）。一场戏同时含文武时出两张或按主戏份选型。
- **教训**：真人影视美学（对峙/留白/蓄势）不可直接移植给 AI 视频模型；吸收任何外部拆解/理论时，必须过滤“静止表演”类规则。

## 2026-09-02 · V6.5-fixed 后增量吸收（35s 玄幻秒级拆解精华）

### 🧩 吸收（Absorbed，2026-09-02，来源：35s 玄幻打斗秒级拆解）

- **Hit-Stop 三件套**：`seedance-render-engine.md` Layer 2 新增——兵刃相碰瞬间 = ①1~2 帧微停顿（打破平滑插值）＋②接触点微观火花迸射＋③双刃咬死高频震颤声（Metallic Screech）。三件缺一，打击感发飘。
- **双实体色彩与材质锚定（混战防混淆）**：`seedance-render-engine.md` §二·五新增——双人/多人对峙严禁只给双方各一个颜色，必须为每一方建立整套锚定（粒子色＋材质＋光效＋轨迹）且双方高反差互补；附黑发剑客（冷银/水墨黑白/玄青轻甲）vs 白发神将（金红烈火/熔岩重铠/阴阳双龙）对照模板。
- **常用音效词库（SFX 可投喂清单）**：`seedance-render-engine.md` §二·五新增——Sub-bass Drop / Sword Ring / Air-cut Whoosh / Sonic Boom / Metallic Screech / Metal Clashes / Shockwave Blast / Supersonic Barrage / Dragon Roar / Apocalyptic Detonation 等 10 类可投喂音效；台词永远走声音层，不写进画面提示词当口型。
- **极限景别跳跃（Macro-Micro Jump）**：`camera-specs-15rules.md` §四新增——ECU 与 EWS 两极极限对跳，制造空间张力与极端体量对比（与单向阶梯互补）。
- **四阶动静呼吸律（Rhythm Curve）**：`camera-specs-15rules.md` 新增 §四·五——长段战斗节奏骨架：静（肃杀）→ 极动（拉满）→ 慢/滞（升格仪式感，全片情绪弹簧）→ 绝杀定格。
- **FPV 主观穿梭机位 / 升格仪式感 / 天地级异象**：`anime-ultimate-vfx-paradigm.md` §一新增 4/5/6 小节——万剑弹幕用跟随第一排 FPV 俯冲；升格慢镜拉长仪式感；通天神魔巨躯（半身烈日半身熔岩）＋引力透镜扭曲＋灭世收尾终帧。

> **未吸收（避免规则重复叠加）**：双色缠绕、急停弹射、环境介质破坏、冲击波、声音层三层解耦等 V6.5 已有权威文件覆盖（anime-ultimate-vfx-paradigm §二 / action-ultimate-finisher §五 / action-previs-15grid §六 / model-adapters 三层解耦）。

- **多人混战独立攻击逻辑铁律（铁律 6）**：`combat-direction-engine.md` §一 新增——多人战斗严禁站桩挨打/排队单挑，每个作战单位必须写清目标+招式+位移轨迹（A 攻 B 同时 C 侧翼/绕后），挨打方也必须写反击/闪避/位移；配合双实体色彩锚定区分参战方。来源：用户分享的“快准狠+独立攻击逻辑”创作观点（仅吸收这一条，超短镜头剪辑观不吸收）。
- **升格慢镜降级为慎用（默认禁用）**：2026-09-02 实测升格慢镜头破坏节奏。`camera-specs-15rules.md` §四·五 慢/滞阶段改为“短蓄力·不用升格”（1~2 紧凑镜头快速带过）；`anime-ultimate-vfx-paradigm.md` §一 小节 5 改为“短蓄力仪式感·慎用升格”。后续生成默认不写“升格/慢动作”，除非用户明确要求。
- **美学构图四件套（Aesthetic Composition Kit）**：`cinematic-dramaturgy-rules.md` 新增 §五——学自 35s 玄幻拆解开头构图（用户对比发现“动作一样但不够帅”）。① 开场 ECU 两极对冲（左右对称双眼特写，各带属性光）② 中心对称·天地立极（极低仰拍+对称异象）③ 剪影/轮廓光/负空间（背光纯黑剪影+属性轮廓光+留白）④ 极端体量对比（蝼蚁微尘 vs 通天巨物）。附组合法则：开场 ECU→天地立极→才进动作；蓄力用剪影→体量对比；收尾回剪影呼应。节奏优先，美学镜头每个 ≤1~2s，不拖节奏。
- **⚠️ 天地异象具象化铁律（2026-09-02 实测翻车）**：裸写“能量光柱/光柱直插云霄”会渲染成两根呆板简笔柱子，整段崩坏。`cinematic-dramaturgy-rules.md` §五·2 已改：严禁裸光柱，必须具象化——① 光粒子洪流版（亿万细碎光粒子自法阵螺旋上升成星尘漩涡，边缘剥落光屑）② 天幕分野版（推荐：不写柱体，写左右半边天被两色能量染透，云层沿分界滚动，人物站两色交界处）。
- **⚠️ 1v1 穿梭感法则·防站桩（铁律 7，2026-09-02 实测）**：天幕分野救活画风，但打斗仍“太像站桩”——模型默认两人原地出招，抽象动势词（穿梭交击/对打）无法驱动位移。`combat-direction-engine.md` §一 新增铁律 7：严禁只写抽象动势，必须写具体位移路径（交叉换位/擦肩而过/穿画面/追击/后撤/绕背/升空/下坠），每镜必有位移动词，运镜跟随完整路径，示例：`两人迎面冲刺，在画面中央交叉换位、擦肩而过，随即回身对撞`。
