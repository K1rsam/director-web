## 版本与安全边界

- 无版本及 v1/v2/v3 仍使用各自旧导出路径；已保存的 `assembly.text` 下载仍返回原字符串，不在读取时自动升级。
- 原生冻结请求、候选、采用稿和回执不迁移。规划后的任务不能通过普通刷新偷换导出版本；未开跑任务的显式刷新继续遵守既有门禁。
- 网页的新建入口显式要求实际原生内核报告 v4。仅热更新网页而原生内核仍缓存 v3 时，返回 `RUNTIME_RELOAD_REQUIRED / NOT_SENT`，在准备源文及创建任务前关门；旧稿阅读不受影响。
- 拉取本补丁不等于运行进程已加载。按[交接版更新说明](3008-RELEASE-20261020-V1.md)保留数据，等待全部在途自然落盘，核对目录、进程和暂停状态后正常重启网页。不能为更新取消在途、删锁或重跑已完成剧集。
- 本次不改生产模型、推理强度、普通/Fast 档位、预算与授权，不增加收费审查岗位。

## 三岗实际输入责任同步

共同创作契约已加入三个职责，实际由统筹、主创、整编的新请求快照携带，不仅写在本说明中：完整读取本次提供的采用版本/简述/自由设计范围/源功能依据；按实际末镜→出口→下一初态→首镜核同场的手别、持物、相位及情绪/呼吸/声音；从实际镜文反查关键物件，复用已登记身份，未登记者回报第一阶段定位、已知键缺设计者回报第二阶段补料。

此前 Web 只供给最多600字的 `brief`、`freeDesignScope`、源依据与参考状态，这一实际差异已补齐：新任务 binding 固定 `adopted-design-text-v1`，对正式采用且当前仍为 READY、提示词版本及 fingerprint 相符的设计，读取保存的完整文字正文，以 `ADOPTED_DESIGN_TEXT_V1` 封装资产身份、采用版本、提示词版本/指纹、正文哈希和用途，不总结或截断尾部。沿现有材料卡→原生输入→材料选择→三岗快照传递，未另改数据库或队列架构。旧 binding 无标记继续 brief-only，历史冻结请求不升级；不可核全文时只供已有简述与scope，不伪造全文或重新生成设计。

全文是 DESIGN 引用，仅消费身份、外观、拓扑、结构、操作及源约束；共同合同明确禁止执行其中的生图指令，七视图版式、生图摄影或示例动作不作为本拍动作/机位。没有读取像素，也不把采用设计提升为 SOURCE。旧原生输入模块缺少正文接收能力时，新建入口在准备源材料前以 `RUNTIME_RELOAD_REQUIRED / NOT_SENT` 关门，防止热更新后只带新版binding却悄然丢正文。

三岗仅报告已提供范围内的身份、版本、消费者和需求；图片目录/既有队列增量由资产入口核对，未提供记录不得宣称已核。新增/修订/复用/移出不自动授予生图权限；本轮没有补造总库项或生成图片。实际镜文遗漏的自动发现和目录/队列语义闭环仍不能算本补丁已实现的通用能力。

鉴权运行身份读取增加 `seedanceExportVersion`、`adoptedDesignTextVersion` 与 `commonContractHash`，用于冷加载后将真实PID、实际导出/输入内核与该进程可读的共同合同身份对应。该哈希不升级旧任务快照，也不证明模型已实际执行新合同或产出了合格接缝。
