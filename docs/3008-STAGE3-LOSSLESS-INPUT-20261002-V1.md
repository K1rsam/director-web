## 修复范围与质量边界

1. 新派单采用 `production-compact-v2`。长源编号、事实坐标和材料编号在单次请求内使用可逆短名；发送数据与输出约束使用同一编号，实时接收、已付回包恢复均按冻结映射还原。映射及完整原件保存在本机，不让模型重新抄写映射表。
2. 已知跨集承接节点改为等值列式表达；顺序、范围、字段和值完整保留。未知节点扩展仍原样发送。
3. 统筹返修只有在原始 JSON 与完整 parsed plan 的差别严格限于字符串外的格式空白时，才复用该完整对象，不再发送第二份同稿。不同内容、重复键、异常 JSON 不推定等值。
4. 除上述可地址化的同稿外，任何原始待修文本或嵌套补充回包均退回原编号，避免新旧编号空间混用。旧短编号的异常回包保留它自己的冻结绑定；已付正文不改写。
5. 新生成约束按未投影原行的证据权限排除 guidance、对白和说者主张，避免辅助信息被误填为 SOURCE。角色说法、设计与解释仍可分别记录；后验来源核验不放宽。

原文、完整对白、括号提示、声音类型、情绪契约、上下文依据、资产卡、实际前包承接、摄影光影和表演幻想要求均未删减。工作包及批次编号作为新镜头前缀时保持原拼写；事实表的正文列、未知说明字段、修正说明不作机器替换。机器坐标只整值还原，不模糊替换正文中的片段。

模型、medium 思考档位、输出格式、创作范围及验收要求不降低。等待时限依据未压缩负荷保留，不能因格式变短提前终止相同创作工作。

这次验证的是数据、接收协议和历史兼容无损，不是新模型生成稿的创作品质实测，更不保证随机生成结果逐字相同。没有新增真实 AI 调用；真实创作稳定性、实际 Token 和费用收益须在后续明确授权的生成中核验。
