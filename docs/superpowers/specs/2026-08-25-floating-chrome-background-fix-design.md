# 悬浮外壳与背景修正设计

## 目标

在 Win 与 Mac 上统一恢复原项目的悬浮外壳，同时保留已经完成的响应式字号与卡片布局。

## 根因

最新响应式样式把顶栏强制改成 `0` 边距，并重新启用了覆盖整页顶部的灰色伪元素；宽屏下工作区间距也被继续放大。因此侧栏仍然悬浮，而顶栏贴边并出现灰条。

## 最终方案

- 页面背景从视口 `0px` 开始铺满；`html`、`body`、路由外壳和应用外壳保持同一浅色渐变背景，默认外边距为 `0`。
- 14px 只作为侧栏和顶栏的悬浮间距，不移动或裁切背景。
- 删除顶部整条灰色覆盖层，顶部 14px 间隙直接显示同一背景，不出现黑边或灰条。
- 顶栏恢复四角圆角、半透明卡片背景和阴影；侧栏维持相同悬浮风格。
- 工作区偏移恢复为固定的“侧栏宽度 + 28px”，不再随宽屏额外放大。
- 保留现有响应式字号、卡片网格、表格滚动和业务行为。
- 登录页与工作台共享品牌图标中的“镜”统一改为“L”；其他正文中的“分镜”等文字不修改。

## 影响范围

只修改共享外壳样式、两处品牌字符和对应的界面契约测试。不修改登录逻辑、数据库、项目数据、API、CLI 或 Runner。

## 验收

- Win 1920×1080 与 Mac 常用窗口下，侧栏和顶栏都是独立悬浮板块。
- 页面最顶部 14px 显示连续的浅色背景，无黑边、灰条或整条遮罩。
- 顶栏四角完整，侧栏到工作区的间距不随宽屏继续增大。
- 登录页和所有工作台的品牌字符显示为“L”。
- 现有测试、生产构建与关键页面访问通过后再发布到当前公开链接。
