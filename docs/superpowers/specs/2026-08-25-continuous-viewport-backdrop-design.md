# 连续视口底图与外壳对齐设计

## 目标

保留顶栏和侧栏的 14px 悬浮间距，同时消除 Win 1920×1080（网页视口约 1920×911）及 Mac 上顶部和四周出现的异色灰边，并让顶栏左右边缘与下方内容对齐。

## 根因

- 同一渐变分别绘制在 `html/body`、路由外壳和 `.appChrome`，滚动与透明叠加时会露出不同绘制层。
- 顶栏左右固定使用 14px，而 `.appMain` 使用 `--vision-page-gutter`，宽屏下两者边缘天然错位。
- `html` 的旧深色背景仍可能在滚动回弹或外壳未覆盖的位置成为兜底色。

## 方案

- 由 `.visionRouteFrame::before` 绘制唯一的固定全视口渐变背景。
- `body`、路由子层、`.appChrome` 与登录页外壳改为透明。
- `html` 只保留接近页面底色的浅蓝纯色兜底，避免回弹时露黑。
- 顶栏继续 `top: 14px`，左右边距改为 `--vision-page-gutter`，宽度交给块级自动布局计算。
- 侧栏继续保持四边 14px 悬浮，不修改业务结构。

## 影响范围

仅修改共享 CSS 与对应源码契约测试。不修改页面数据、登录逻辑、D1、API、CLI 或 Runner。

## 验收

- 页面顶部仍有 14px 悬浮空间，但显示连续底图，不出现灰边或黑边。
- 顶栏左右边缘与主内容卡片边缘一致。
- 侧栏外围显示同一连续底图。
- 页面滚动时底图固定，路由切换不会重新起算渐变。
- 全部测试与生产构建通过后发布到现有公开链接。
