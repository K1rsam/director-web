# 第三阶段表现与节奏定版修订 V3

本轮按用户授权实施，接续质量保全 V2 与节奏修订 V1；不覆盖历史结论。目标是减少可见的批量套法，并保住已经形成的爽感、源文保真及可执行的声画细节。评分和视频效果仍须新稿及实际观看验证，工程检查不等于创作品质验收。

## 为什么还要修

核对新两集保存稿、各岗实际请求及冻结规则后，确认不是这两集没有启用上一轮内核，而是规则仍有以下引导风险：

- 上一轮“常规2–5秒、长镜说明例外、每30秒镜数参考”容易被模型当统一模板。新两集104镜均落在2–5秒内，不能据此证明镜头选择合理。
- Q版的身份连续说明被当成反复播放的同一种变身过程；统筹先把许多不同回报预定为Q版，主创再沿提案照写。
- 摄影的“短促后移、脸大小不变、背景压近”示例形成另一个可批量复制的方案。只把缓推换成推拉变焦不是摄影进步。
- 字速合计看似接近基准，但跨镜声窗之间仍可能重复留缓冲。合计声窗不等于首声至尾声的历时，正文“立即、不断声”也不能代替实际时间安排。
- 默认Mac合成平读约4字/秒的数据可能成为慢读锚点；这是参考引导风险，不声称已证明它是唯一原因，更不能当演员实配下限。

证据样稿：`storyboard-bf2c7aa7-60fc-4746-a074-124f4d27a573.md`（第一集）、`storyboard-a3aeef6b-7e9b-46ea-9e12-100b68db63b9.md`（第二集）。保存原稿和付费请求未重写。参考《天狗》《腿拉弓》主要借关键变化的速度轻重、可读受力及余势，不照搬其角色、镜数或事件。

## 改在哪里，怎样避免拆东墙补西墙

1. **镜长重新成为演出选择。** 新规则取消2–5秒区间、普通短镜下限、长镜例外审批和镜数目标。连续观看有收益就保留，需要新观看关系才切；不把全部镜头变长，也不以快节奏强制短切。旧数字只在冻结旧协议中保留。
2. **在统筹入口选机制，而非批量选Q。** 先交准刺激、主动关系、作用对象及独特回报，再从身体、局部脸、真人/化身关系、尺度空间、源知识图示中择优。内部连看相邻提案，遮去人物与材质后仍雷同的，就在本岗重设计；有效同构累积、反用与群体齐反应不误删。没有形式配额、新报告或新付费岗。
3. **身份连续不等于同一种变形动画。** Q形象仍保留必要原设辨识、材质和受光，但变化从当前动作、阻力和落词设计，不再默认“头肩膨大、躯干缩短”。二维、局部脸、2D/3D混合、化身和全幅意象均保留。进入、发展、释放和恢复的时间重量由此拍需要决定，不改成另一套统一三拍或弹簧流程。
4. **摄影变化有观看用途。** 修订摄影方法与表现性强调卡，推拉变焦继续可用，却不再默认代演所有受辱、惊讶、威压。遮挡揭示、人物侵入画幅、视线交棒及成立的静机对照都可择优；更换术语不算真正变化，也不以稳定为由把强镜头全降成静机。
5. **声轨先按完整原句组织。** 每分钟约300–360有效字作为清晰快节奏起排，情绪可浮动至约240–420字，非逐句硬限制。可以简要写“约330字/分，反问重读、原句内自然换气”，不逐镜抄参数。跨切不重吸、不重置气口；必要停顿与有收益的无对白过程保留。
6. **程序提供真实间隔坐标，现有整编负责联修。** 新增完整原句跨镜/连续单元的声窗合计、首尾历时和间隔坐标，以及相邻原句接话间隔。只在原话完整重建、时间窗有效且连续范围明确时计算；未知镜长、跳时、换场、残句和非词语发声不误指控。间隔不等于空白，不产生自动改时、暂停或调用。整编按实际作用局部修声画与切点，不能只改措辞或duration。
7. **默认平读只归档，不再作为新请求目标。** 仅识别既有Mac `Tingting rate200` 标准参考形状，省去本次发送的测读数值；原缓存、原稿不删。自定义参考及未知字段保持原有投影。摘要保留兼容的`rows:[]`，不让省参考意外关闭原有等值引用压缩。

本轮替换七处既有技能/共同契约及一张方法卡的相关段落，合计净增123个UTF-16字符；不是追加一套更长的全稿自查指令。

## 必须保住的能力

- 原话逐字、说者、声道、表演提示分离、源顺序与知情边界。
- 独立世界理解、期待/受辱、私下得势、公开反击、真实危机与救援、关系主动退出及亲情落点；不以一个高潮冒领其它回报。
- 已选幻想的强度、全幅/近脸、有效长驻留、跨镜连贯与具体人物作用；不退成小图标，不为占比或易做而降档。all/recommended/off及取消边界不变。
- 真实受力、相机/演员可达、动作余势、光影声音；未来形象不冒充当前形象，主观展开不暂停现实同期运动。
- 集内串行承接、不可变请求、既有差量返修和正确单元沿用；不新增付费裁判或重读全剧。
- 靠近容量的合法切点、整数单元终点及镜内小数；30/30/7自然短尾不均分、不补戏。本轮不实行重复搬运相邻单元来凑时长。
