## 已实施

1. **同稿转单稿复核。** 按完整正文逐字符比对，保留标点、时码及换行；同稿不再输出两份A/B、不显示采用按钮，服务端拒绝重复采用，不写归档或采用关系。不同稿只记录实际差异坐标，不把“有差异”当“提升”；采用后仍绑定精确归档原稿。基稿不可验证时拒绝错配对照。
2. **范围落实到完整单元。** 新版在1至2个连续事件内选择连续完整单元；展示单元/镜数、简短首尾源锚及“全集/局部”。跨单元幻想不可只选一半；不自动扩大范围。同事件内未选单元也不可改。前端提前提示，派单与回包仍由服务端验证。
3. **一次简短工作单。** 可填具体观看问题和必须保留功能，各不超过1200字符，不新增外部参考上传或自动复读旧稿。新协议要求每个选中旧单元登记一次 `reviewDecisions`，可按同一问题合组：`changed/retained/unresolved`、具体依据、保全功能。对应实际差量；未解决须有坐标。允许有依据的保留，不强迫为证明工作发生而硬改。
4. **精修skill补执行方法，不重写普通三岗。** 先定位原话、动作起效、听者、揭示及落点，共看声画时间线；低字速/单镜驻留不直接定为拖慢。有效慢说、气口、接纳、压迫和护子保留；只有实际提供的同源旧稿才可借鉴其机制，不冒称读过参考。范围外依赖记未解决，不全局改镜长、语速或幻想形态。处理账不复制整段原文、整表或修订报告。
5. **方向与坏回包提示。** 页面及审稿材料明确本任务是否实际采用全剧方向，不自动采用草稿、补历史输入或新增AI读取。坏回包中的畸形处理说明仅保留原始证据与校验错误，不让页面因字段类型错误崩溃；正常三岗成果仍可读。
