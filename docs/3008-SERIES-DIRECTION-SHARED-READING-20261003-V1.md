# 全剧方向共用第一阶段读取 V1

2026-10-03。本文件追加现行实现，保留 `3008-SERIES-DIRECTION-CONTRACT-V1.md`、方向恢复 V2、上游 Token 审计 V1–V3 的历史结论。对应第三阶段追加记录 S3-E0038。

## 修改目的

此前方向编辑、采用与第三阶段投递接口已经存在，但第一阶段 F2/Q1 不生产方向候选。资料完成不等于方向完成；空方向面板不能当作模型已经判断过全剧。

本轮将候选作为既有 Q1 原文核对的独立附加结果，不新设方向岗位，不让 F2 和 Q1 分别写一次方向，也不撤掉仍有质量作用的首次语义资料核对。全剧方向由用户采用，模型不自我确认。

## 生成过程

| 原有处理 | 方向任务 | 不生产的内容 |
| --- | --- | --- |
| F2 基础资产目录 | 不附加方向 | 第二份全剧总结、方向重复草稿 |
| Q1 首次完整核对，一次覆盖全剧 | 顺带返回精简方向候选 | 独立全剧阅读及第二次综合调用 |
| Q1 长稿前面的分批核对 | 每批仅 1–3 条有原文引文的关键方向依据 | 每集剧情摘要、不断增长的前批历史 |
| Q1 最后一次既有核对 | 结合本批原文与此前精简依据，汇总一次候选 | 再回传所有前批原文和目录 |
| Q1 局部返修/采用决定 | 不重复判断全剧 | 小问题触发重新阅读整剧 |

分批引文最多 100 Unicode 字符，解释最多 120 字符；引文须确实属于本次已发送片段。前批依据只在最后一次现有核对中汇总一次，属于解释候选，不升级为原文事实。程序以实际请求、回包、原文 UTF16 半开区间和来源版本核验完整覆盖，不能相信模型自行填写“已读完全剧”。

作者背景在最后一次共用核对、形成候选时完整提供一次，不假设无会话任务记住了早批背景；准确可还原的背景事实正文改为引用该正文的原文坐标，保留类别、角色主张、适用性与有效性。外部解释、不匹配坐标、未知协议/根元数据或扩展形状均保留正文。各批资产核对若确需相关背景事实仍允许读取，不能为了减负省掉必要适用性依据。

作者背景附加正文超过 6,000 UTF16 字符、最后批次的此前依据包超过 10,000 UTF16 字符，或现有任务未实际覆盖全部来源时，不截断后谎称完成；保留正确资料并显式提示方向待补，不自动另购综合调用。

## 接收接口与历史

- 请求：`seriesDirectionPreparation.version = FOUNDATION_DIRECTION_READING_V1`；模式为 `COLLECT` 或 `FINAL`。仅本次正在阅读的源文、必要作者背景与最后批次的 `priorSignals`。
- 回包：`COLLECT` 返回 `seriesDirection.signals`；`FINAL` 返回 `seriesDirection.content`。内容仍使用既有 `SeriesDirectionContent` 字段与边界。
- 回执：`SERIES_DIRECTION_FOUNDATION_RECEIPT` 保存不可变来源、实际 runId、覆盖区间与独立格式问题。方向回执与正确资料采用在同一事务提交。
- 候选：保存为现有 `SERIES_DIRECTION_CARD`，`origin = AI`；`foundationReading` 绑定实际读取回执。只更新草稿，不修改当前采用卡。
- 并发：人工草稿优先；迟到模型候选只入历史，并保留唯一修订编号。旧源回包不能被采用为新源方向。
- 旧回包：原有正确资产回包即使没有新字段，也可免费恢复；不得因新增方向功能重新购买相同资料。未知请求与未知用量的原有安全边界不放松。

缺方向或方向格式不合格不算正确资产损坏，不能据此返修整套资产。自动闭环遇到资料已完成但无方向候选时提示补充，不自动发起旧的独立全剧分析；已有独立分析回包的安全恢复路径保留。

## 网页采用与第三阶段消费

第一阶段的“剧本阅读与全剧方向”显示共用读取进度、候选、来源覆盖与采用状态。正常候选核对后勾选认可，直接“确认采用”；修改内容仍先保存新草稿。已存在人工草稿或采用卡时不自动覆盖。

独立 AI 分析放进默认收起的“额外分析（通常无需使用）”；明确提示会重新读取全剧并额外计费。已有共享候选的重复生成在创建模型任务前拒绝，只有明确要求额外重做才放行。资料正在整理时不并行另开全剧方向分析。

独立补充分析的规模限制不阻塞已有共享候选的核对采用；真实来源缺口和已有未知回执仍按原安全规则处理，不借此绕过。

第三阶段沿用现有确认投影，只携带当前有效方向短卡（目标约 200–350 字、程序上限 600 Unicode 字符），不携带候选历史、完整目录、分批引文或再次分析的全剧正文。未确认/过期的卡不能冒充锁定方向。历史请求快照不被新方向改写；后续实际执行仍按原有有效材料校验。

全剧主调不压平单集变化，标签不代替事实，不提前套用未来身份、角色知情或揭示；逐镜表演、机位和幻想演法仍由第三阶段创作。第二阶段按需要补设计的流程保持，不为方向任务强制全资产再生成。

## 成本边界与旧项目

“零额外方向派单”不等于“零额外 Token”：Q1 多了一项精简候选职责，必要指令与输出仍会消耗 Token。没有真实模型运行，不能给出节省比例、真实费用或断言创作质量无损。本轮不修改模型参数和预算停止线，不调用 Jev。

已完成的旧项目（包括当前《全民》）不会在打开页面时自动收费补候选，不重跑已完成的一、二阶段，也不把旧结果伪造为已做全剧方向分析。可以直接人工补卡；确需 AI 补充时明确发起额外分析。新一轮首次资料整理自动使用共用读取方式。
