# 全剧情绪、快速摄影与幻想偏好

## 用户反馈与边界

本轮反馈是幻想不够大胆、情绪力度不足、运镜虽然有动但多数感觉过慢。未在本轮直接复看视频，不把文字抽样或关键词数量当视频速度/质量测量；不重跑、改写或重新购买已完成的150集。

根因分层：源码此前没有可保存的三维强度选择；实际文字样本中存在只交代相机路径、未交代速度/命中相位的镜头。它们是可修的程序与指令缺口，不足以证明所有成片平淡都由同一因素造成。

## 全文评估后的免费确认

复用第一阶段既有Q1共用读取和“全剧创作方向”卡，不新增模型岗位或采用调用。分批COLLECT仍只保留1–3条有原文短引的关键信号；实际累积覆盖完整、背景齐备且预算允许的最后既有Q1才汇总建议。它不是最后一次调用重新读完整全剧。

新候选分别建议：

- 情绪：自然有层次／强烈鲜明／高幅夸张。
- 镜头：动静有别／快速有冲击。
- 额外幻想：少量精准／适度择优／丰富大胆。

持续嘴贫、荒诞反差、喜剧交锋适配时主动考虑更高幅情绪、快速摄影及丰富幻想，并说明需保留重量的段落；不凭“喜剧”标签机械选满。理由是待核对的创作解释，不是剧情事实、永久角色状态或完整认知证明。

第一阶段完成处明确提问并链接既有方向面板。用户可独立修改任一维度，未设置维度沿用原口径；任何修改清除认可勾选并要求先保存。保存草稿与确认采用使用原本免费接口、权限、来源、hash及CAS，不进入humanChoice的全剧Q1重新应用队列。AI候选或已保存草稿均不投递；确认后同一精简brief进入各集实际统筹、主创、完整/差量整编请求。

旧卡缺字段时不补对象、null或强默认，hash与旧brief不变。旧项目缺建议、已有方向或未能完成共用综合时，可手工选择，不自动重读全剧、不伪造全文评估。独立补充分析仍须原有费用确认，本轮没有启动它；如未来另行授权，综合阶段使用同一内容schema。旧保存回包不偷换新语义。

## 执行而非口号

强情绪落实为欲望、身体、对向受力、策略与关系反差，不靠只写“愤怒、激动、夸张”，也不是全员吼叫。强者不动、对手剧烈失守也可有强回报。

快速摄影在实际camera写明触发、迅疾路径、命中对象及可读落点/接续。例如“关键词出口时，沿他前指的手短促急推到对手近脸；对手撑住的笑卡断，镜头刹稳读清眼口变化，随其后退接向下一回应”。这是方法例，不增写任何一集的剧情，也不是每镜套用的固定急推—刹停模板。只写“移近、侧移、退移”还没有说明快慢。必要辨认、悬念、伤痛或落定可慢可静，不催读、吞字或用模糊遮掉接触。

丰富幻想主动在实际源锚寻找更多独立表达收益，放大胆量与意象机制：人物在形体、尺度、关系空间或内外心思的具象演出中继续争取、躲避、拆台和回应，不只增加贴纸或Q版标签。密度、幅度与搞笑程度分开，不按数量/比例凑幻想，不每镜变形，不消解真实痛苦。

全剧偏好不修改fantasyMode或逐项选择；off、用户取消、源事实/原话/因果/揭示时点仍优先，源明确视觉及真实能力保留。叠字确认独立有效，丰富幻想不自动允许时间/身份/等级介绍字幕。整编在原本同次范围里联修，不新增收费裁判。

## 数据与验证
