原数据库已有约 70 个索引并启用 WAL。慢读主要来自页面逐项目完整重读、多次解析大 JSON、为获取最新资料扫描历史，以及重复轮询；不是本地数据库完全没有索引。

| 修改 | 效果与边界 |
| --- | --- |
| 项目库读取小型投影 | 当前 22 个项目仅 4 个需要完整完成度核验，其余用必要条件证明未完成；投影绝不直接证明完成，不将旧状态缓存成完成 |

| 保真候选按需投影 | 只取源绑定候选所需的正文和坐标，原附件 base64 与重复分支不进入此读取；完整导出与修改仍读取原始凭据，重复 JSON 键和旧异常形状走原语义回退 |
| 资产工作区复用已读材料 | 同一次请求内复用来源和文档；变更操作的来源校验仍读取新证据 |

| 图片执行器读取 | 只读取需要执行或恢复的状态，合并相同资产键集的绑定读取；历史和重复 JSON 键保持原 `JSON.parse` 判定，未改变 UNKNOWN 或重复派发保护 |
