# 混合长短稿与局部选择依赖

已接实际controller：超过24000字符的集独立采用原18000字符分片，只在原文连续短集段内合批，保留原F2源批次上限并额外检查完整请求预算。F2/Q1都按原文次序执行短段→长集全部片→后续短段，禁止跨越长集空洞合批，以免historicalStates与前接资料遗漏中间长集。

每片Q1保存依赖指纹：片内原文、局部场次、该集身份名称/类型/别名和明确适用的选择，以及实际项目设置。局部选择变化只清除受影响片，未知范围不当全剧。明确GLOBAL才广泛失效。旧仅q1Basis记录只有basis相同才迁移保留；无法核实的旧依赖保守重校验，原付费证据不删除。

已付费但未应用的短批范围优先恢复；原call精确片证据恢复路径保留。身份供给接入safe selector，不再按本片名字出现与否丢掉完整最小身份索引。

## 实测

- `verify-foundation-mixed-fragments.ts`：独立SQLite、真实controller+mock provider。顺序为短集[1]→长集2全部片→短集[3,4]，各阶段短批均不重复；长集源切片恰好一次完整覆盖。第2集末尾受伤，第3集承接，直接核对实际model wire的历史状态保留该受伤及前接资料存在。故意在首长片响应后令文稿保存失败，继续后免费恢复该片。新增首场确认选择后，仅第一个受影响片调用一次Q1，无F2或无关短集重复。
- `verify-foundation-fragment-work.ts`：局部scene选择、无关集、明确GLOBAL、旧依赖元数据逻辑通过。
- `verify-five-step-fragment-runtime.ts`：长单集原文覆盖及下游交接通过。
- `verify-unactionable-repairs.ts`：全部费用保护回归通过，未更改费用断言。

## 边界

本轮解决选择变更的局部片失效；来源版本更改仍遵循现有全sourceVersion的片ID和文稿版本机制，不声称跨源版本已实现局部重算。身份范围保守保留该集身份信息，未自动推断所有状态传播。字符合批不是实测token/速度结论。上述测试未调用真实模型、未改生产库和用户稿。
