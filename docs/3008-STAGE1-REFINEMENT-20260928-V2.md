# 第一阶段接收修复与Token减负 V2

日期：2026-09-28。仅本地3008；未提交、推送或更新GitHub。V1报告和原始失败记录保留。

## 已落到真实路径的修改

- **标准正文接收**：由程序建立原文片段映射，明确说者、声道、提示、正文及辅助备注；接入第一阶段P4与第三阶段输入，不再把分行对白重新按冒号猜一次。原句、真实换行、引号内冒号与字面量反斜杠保持。
- **分项就绪检查**：缺说者依据、无法安全区分的续行、同一行多个说者等给出具体行号并阻断；不把它们交给Q1无限重写。第一阶段状态、交接与派单都能看见正文问题。
- **证据闭合**：接收包摘要、原文索引、字段来源、整行覆盖、顺序、完整对白目录、cue与声道均验证。辅助意见单独保留，不能自证剧情事实；工作包切片不删除这些说明，不能拿局部切片冒充整集。
- **事实索引纠错**：新路径基于同一分型结果生成检索提示，去掉“第一集”“出场人物”“你刚才说”等伪说者。旧协议仍保留原算法用于已有任务。
- **连续性关联**：新路径要求同一资产key在前场/当前场均有使用依据，不能只凭同名继承另一个对象。道具显示名带外观修饰不再妨碍关联。
- **岗位规则与协议**：F2不再收到Q1回执指令；没有对应待办的Q1不再携带那类回执格式。精简重复字段解释，保留权限、范围、未知问题和新humanChoices出口。继续禁止无用途的概述、逐集/逐场复述和自评稿。
- **模型传输**：规范证据仍保留，重复事实变成一份表及分组引用；未知字段、历史正文、冲突文本不删。最后又把F2/Q1的分型提示收缩到跨行、特殊声道、备注及未决位置，避免另送一份普通场稿。第一阶段原文仍完整发送。

实现入口：`lib/standard-script-plan.ts`、`lib/standard-script-reception.ts`、`lib/foundation-production-prompts.ts`、`runtime/storyboard-v4/core/standard-source.mjs`、`runtime/storyboard-v4/core/fact-projection.mjs`。
