Usage:
  dreamina multimodal2video [flags]

Upload local images, videos, and audio, then submit Dreamina's flagship multimodal video generation mode. This corresponds to the "全能参考" (All-around reference) feature on the web interface (formerly known as ref2video). It supports Seedance video models (flag values: seedance2.0, seedance2.0fast, seedance2.0_vip, seedance2.0fast_vip, seedance2.0mini, seedance2.5). The task is asynchronous, but --poll can wait briefly before falling back to query_result.

Supported combinations:
- inputs: any mix of --image, --video, --audio
- seedance2.5 -> audio-only is allowed; image<=30, video<=10, audio<=10, total inputs<=50; each and total video/audio duration 2-30s; video_resolution 480p, 720p, or 1080p; output duration 4-30s; VIP-only
- seedance2.0 family/seedance2.0mini -> at least one --image or --video is required; image<=9, video<=3, audio<=3, total inputs<=12; each and total video/audio duration 2-15s
- seedance2.0_vip -> video_resolution 720p, 1080p, or 4k
- all other seedance2.0 models -> video_resolution 720p
- ratio: 1:1, 3:4, 16:9, 4:3, 9:16, 21:9

Notes:
- --video_resolution is required
- default model_version: seedance2.0_vip (unchanged)
- default duration: 5s
- omit --ratio to use 16:9
- local files are uploaded automatically before submit and use model-specific duration validation
- input counts, permissions, and runtime availability are ultimately determined by backend configuration
- duration, video_resolution, and any explicitly supplied ratio are strictly validated; unsupported or legacy values are rejected instead of silently adjusted
- 部分模型首次使用时，需要先在即梦 Web 端使用该模型完成首次生成。若提交生成任务后返回 AigcComplianceConfirmationRequired提示，则属于该情况。 For some models, first-time use requires completing an initial generation with the model on Dreamina Web. If the AigcComplianceConfirmationRequired message is returned after submitting a generation task, this requirement applies.


Flags:
      --image stringArray         repeat for each local input image path
      --video stringArray         repeat for each local input video path
      --audio stringArray         repeat for each local input audio path
      --prompt string             optional multimodal edit prompt
      --duration int              video duration in seconds; supported ranges by model: seedance2.5 -> 4-30; all other models -> 4-15 (default 5)
      --ratio string              supported values: 1:1, 3:4, 16:9, 4:3, 9:16, 21:9
      --video_resolution string   required; supported values by model: seedance2.5 -> 480p, 720p, or 1080p; seedance2.0_vip -> 720p, 1080p, or 4k; all other models -> 720p
      --model_version string      supported values: seedance2.0, seedance2.0fast, seedance2.0_vip, seedance2.0fast_vip, seedance2.0mini, seedance2.5
      --session int               session id (default 0 "默认对话") 
      --poll int                  submit then poll query_result for up to N seconds at 1s intervals (0 disables polling)
  -h, --help                      help for multimodal2video

Global Flags:
      --version   print build version information

Examples:
  dreamina multimodal2video --image ./input.png --prompt="turn this into a cinematic shot" --video_resolution=720p
  dreamina multimodal2video --image ./input.png --audio ./music.mp3 --model_version=seedance2.0fast --duration=5 --video_resolution=720p
  dreamina multimodal2video --image ./input.png --video ./ref.mp4 --audio ./music.mp3 --model_version=seedance2.0fast --duration=5 --video_resolution=720p
