# 资产列表与第一阶段来源冲突修复

2026-10-05 修复两处问题，保留现有界面和旧版 Skill 工作流程。

## 第二阶段资产卡片重叠

资产网格处于高度受限的滚动区域中，默认隐式行会被压缩，卡片内容超出行高后相互覆盖。为网格指定 `grid-auto-rows: max-content`，使每行按卡片实际内容占用高度，其余布局不变。

离线浏览器使用实际 React 资产面板渲染，覆盖 1、58、200 项资产，有图和无图，以及三种窗口尺寸，共 18 组。修复后卡片不重叠，最后一项可滚动到达。

## 第一阶段已有形象的制作来源建议变化

F2 重新整理资料时可能建议把已经登记为直接参考的形象改为派生制作。旧实现把建议当作对既有来源的直接修改，因而在进入 Q1 前拒绝整批资料。

现在先验证完整的建议来源图；对身份一致的已有形象保留已登记的制作方式与来源，把建议差异作为原有 Q1 整编流程中的待判断项。Q1 可以明确调整为合法来源，也可以保留原来源并结束该项。身份、必填字段、原文引用、适用范围、悬空来源和循环来源校验继续生效。

已因这一特定校验拒绝的 F2 返回，仅在流程、步骤、规则、输入、执行器及完整冻结快照一致时重新验证同一份结果。重放保存审计记录，不再次调用 F2；上下文变化则拒绝复用。原始任务和结果字节保持不变。
