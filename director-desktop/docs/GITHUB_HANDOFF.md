# 桌面端源码交接：2026-10-05

本目录是当前 Windows 桌面制作工作台的源码快照，与仓库根目录的旧 Web 项目并存。开发命令在 `director-desktop/` 内执行。该次上传先保存现有版本，再另行修复资产列表布局及已有形象制作来源冲突。

## 当前运行框架

Tauri 2 + React/TypeScript + Rust + SQLite。第一阶段沿用 F2 → Q1，第二阶段输出资产图片，第三阶段沿用情绪规划、单元主创、整编，第四阶段完成素材绑定与视频任务恢复。规则随执行任务冻结；旧 Web 项目不是桌面端的运行依赖。

第一阶段新的短身份传输配置仅用于新发起的流程，旧流程沿用冻结快照。原文、身份与来源在核心中仍使用完整规范值；实际模型输入的短编号由 Rust 编译并在回复后还原。

提交源码、规则、构建锁文件、图标、脚本和编译期使用的回归样本。项目 SQLite、生成媒体、任务运行目录、凭据、旧备份、安装包和第三方程序二进制不提交。历史本机验证文档中的运行记录路径可能只在原机器存在。
