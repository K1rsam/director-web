# 资产管理与第一阶段修复

第一阶段只将有当前原文证据的资产加入来源注册表。独立试图、手动测试角色和图片提示词不会自动成为剧本事实；类型由可信适配层转换，稳定身份保持不变，同名主体不合并。原文及源引用仍严格校验。

第二阶段选中资产后，右侧标题处提供“编辑资产”“删除资产”。编辑名称、分类、派生来源与适用集场，固定身份只读。选集时默认覆盖该集全部已识别场景，也可指定具体场；保存同步更新 `scope` 和 `applicability`。修改来源会使旧设计参考失效，提示词与版本历史保留。

删除将资产移出当前制作目录，追加删除版本。删除确认展示关联单元、派生形象及任务；没有关联的测试资产可直接移除，有关联也可删除并随后修正。原图、历史版本、任务回执与已提交快照保留；“已删除资产”入口可恢复。云端已知 ID 继续查询下载，未知提交禁止自动重发，晚到图片只保留为历史，不复活资产。

第四阶段每个单元的素材区提供“调整配图”：替换主体/形象、增减配图、修改用途及顺序。替换精确身份标记，不按名字改写创作文字。移除后仍有素材标记或失效身份时，要求明确修正提示词。保存新单元版本，仅作废关联的未提交素材包，已提交任务保持原样。历史图片如需再次使用，可在第二阶段切回当前图片。

原文和制作基础更新仍遵守版本门禁：流程运行中修改资产或原文，不能把旧输入成果覆盖到新版本。删除发生在基础流程开始前，旧基础可保留事实，但不会恢复已删除图片目录项；开始后删除则阻止过期发布。

验证使用隔离项目与真实 V5 原文的只读快照。十集 mock 重放验证到文本执行及基础校验，不代表真实模型创作效果。Rust 全量、实际组件回调、Windows 桌面 IPC、原图读取与恢复分别记录在 `docs/verification/asset-lifecycle`。没有付费生成、安装包构建或用户进程关闭。
